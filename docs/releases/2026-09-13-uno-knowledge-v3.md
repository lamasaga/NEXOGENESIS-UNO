# UNO 知识处理 v3 关键版本

日期：2026-09-13。Git 标签：`uno-knowledge-v3-20260913`。本版本保存 UNO 程序重构，不包含实例知识、模型凭据或本地运行状态。

## 版本范围

- 平等的多知识库目录与项目关联知识库；每项处理任务绑定自己的目标库。
- 小批预处理、主题 Buffer、原文检索、模型自主成卡、独立审核上下文与通过对象发布。
- 多 TAG、摘要和必要正文结构、独立领域导航、可追溯来源、图片归档与历史版本。
- 每轮意图识别与按需集中检索；无需材料的问题直接回答。
- 按库保存知识处理偏好，长期与本次要求合计 3000 tokens；按钮和斜杠入口共用简化后的开始面板。
- 模型连接设置优化。启动脚本尊重已有知识库登记，避免自动重建已经移除的旧库目录。

详细行为与限制见[整体重构实施记录](../UNO-整体重构实施记录.md)。

## 本轮核验

- 后端测试 281 项通过，前端测试 163 项通过，前端构建通过。
- 3093 运行服务只登记并启用“默认知识库”；卡片、待处理材料、编译任务和图谱节点均为 0。
- 默认库八个知识与产物目录均无文件；运行程序可以生成空图谱缓存。
- 模型配置文件与初始化空库之前的 SHA-256 一致，已配置的 DeepSeek 密钥状态保留。
- 知识库、运行目录及本地验证截图不纳入程序提交。可编辑设计页、契约示例和合成测试保留为开发资产。

这些验证不证明真实模型的材料理解质量、审核收益或 Token 成本优于旧流程。构建仍有单个资源包超过 500 kB 的提示，不影响本次构建通过。
