# 2026-09-04 纯净初始化发行包

  纯净初始化发行包只交付可重建的 Agent 运行项目，不交付任何实例知识或运行现场。接收方解压、安装依赖并构建前端后，得到一套空白知识目录，可以从对话、导入材料或新建知识实例开始使用。

## 一、进入发行包的内容

| 类别 | 内容 |
|---|---|
| Agent 规则 | `AGENTS.md`、`.agent/skills/`、`.agent/reference/` |
| 运行代码 | `packages/nexogenesis-tools/lib/`、`packages/nexogenesis-web-host/lib/` |
| 运行模板 | `schemes/default/`、preset、profile patch |
| Web | 生产源码、构建配置、`package.json` 与锁文件 |
| 准备与启动 | `prepare-nexogenesis.ps1`、`start-nexogenesis.cmd` |
| 当前说明 | 面向发行包的精简文档入口，以及 AGENTS 索引指定的当前事实、架构、路线、实施与评测说明 |
| 空白知识目录 | `00-Inbox/` 至 `07-Conversations/`，全部不含文件 |

  `.agent/reference/card-contracts/card-exemplars/` 与 `schemes/default/card-exemplars/` 中的 Markdown 是写卡格式正例，属于 Agent 的运行契约，不是实例知识；检索器只读取 `01-Cards/`，不会把这些正例当成知识库 Card。

## 二、明确排除的内容

- `01-Cards/`、`02-Profile/`、`04-OutBox/`、`05-Buffer/` 等知识与派生产物中的全部文件
- `00-Inbox/`、`03-Archive/` 中的原始材料
- `06-Journal/`、`07-Conversations/`、`.nexogenesis/`、`instances/`、`tmp/` 等运行状态
- `node_modules/`、`web/dist/`、缓存、日志、源码映射和 TypeScript 增量构建文件
- 单元测试、性能测试、评测夹具、真实回归案例、历史文档和开发现场记录
- `.env`、实例清单、压缩归档及 PDF、EPUB、Office 等材料文件
- 打包器自身和部署契约；接收方拿到的是运行项目，不是发行生产工具

## 三、生成与使用

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\export-clean-agent.ps1
```

  默认输出到仓库同级的 `NEXOGENESIS-DSH-distributions/`。ZIP 内带有内容清单与逐文件 SHA-256，外部 release JSON 记录整包 SHA-256。工作树未提交时文件名带 `working`，只能视为当前工作快照。

  接收方解压后在项目根执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\prepare-nexogenesis.ps1
```

  准备脚本会确保空白知识目录存在，按锁文件安装三套 Node 依赖、构建前端，并把实际解压路径写入用户级 DSH 配置。准备完成后运行 `start-nexogenesis.cmd`。

## 四、与便携知识体包的边界

  `export-clean-agent.ps1` 用于分发一套没有知识内容的新项目。`export-portable-snapshot.ps1` 用于迁移某个现有实例，后者会主动携带 Card、Profile、OutBox 与 Buffer，不能再称为纯净核心 Agent 包。两种发行目的不同，不应混用。
