# 数据字典

## `forecast_vintages.csv`

  保存同一目标的不同预测版本。`allowed_checkpoint` 决定该行能否进入模型输入；`research-only` 和 `outcome` 永远不能进入 T0—T2。

## `precrisis_signals.csv`

  保存同期材料中可以定位发布日期的结构信号。不同指标的可得时间不同，因此不能把整张表一次性交给 T0。运行测试时应使用输入 Markdown；CSV 供研究者核查和未来自动生成 fixture。

## `outcomes_1996_1998.csv`

  数据来自世界银行 API 当前历史版本，抓取于 2026-08-29。字段含义如下：

| 字段 | 含义 |
|---|---|
| `gdp_growth_percent` | 不变价 GDP 年增长率 |
| `cpi_inflation_percent` | CPI 年通胀率 |
| `official_exchange_rate_lcu_per_usd` | 每美元对应本币数量的年平均官方汇率 |
| `current_account_percent_gdp` | 经常账户余额占 GDP，正值为盈余 |
| `real_export_growth_percent` | 货物与服务实际出口年增长 |
| `real_import_growth_percent` | 货物与服务实际进口年增长 |
| `revision_vintage` | 本地冻结该历史版本的日期 |

  世界银行 API 指标代码分别为 `NY.GDP.MKTP.KD.ZG`、`FP.CPI.TOTL.ZG`、`PA.NUS.FCRF`、`BN.CAB.XOKA.GD.ZS`、`NE.EXP.GNFS.KD.ZG` 和 `NE.IMP.GNFS.KD.ZG`。
