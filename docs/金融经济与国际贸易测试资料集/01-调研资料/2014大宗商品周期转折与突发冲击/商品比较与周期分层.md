# 商品比较与周期分层

## 一、商品结构对照

| 商品 | 主要需求 | 供给调整速度 | 库存作用 | 典型短期冲击 | 本案例长期信号 |
|---|---|---|---|---|---|
| 原油 | 交通、工业、石化 | 已投产油田慢；致密油钻井较快但产量有滞后 | 商业库存和剩余产能可缓冲或放大 | 战争、制裁、OPEC 决策、飓风 | 高价推动美国致密油、加拿大油砂和其他非 OPEC 供给 |
| 铜 | 电力、建筑、设备和制造业 | 新矿建设慢，既有矿也受品位和罢工影响 | 交易所与企业库存影响短期价格 | 矿山中断、罢工、补库去库 | 2000 年代高价推动矿业投资；中国需求占比接近全球一半 |
| 铁矿石 | 炼钢和基础设施 | 大型矿山建设慢，但投产后产量集中且成本低 | 港口和钢厂库存重要 | 港口事故、天气、钢厂限产 | 澳大利亚、巴西大型低成本产能集中释放，价格竞争淘汰高成本矿 |
| 小麦 | 食品、饲料和贸易储备 | 一年一季或多季，下一播种期可调整 | 库存消费比是跨季缓冲 | 干旱、霜冻、洪水、出口限制 | 长期趋势较弱，年度天气、面积、单产和库存更重要 |

## 二、四种容易混淆的判断

### 1. 短期上涨不等于长期上行

  2014 年二季度，伊拉克局势推高油价，小麦也因天气和供应担忧上涨。但同期美国原油产量继续增长，铁矿石新增供给已经压低价格。测试应检查模型会不会把最新价格动量机械外推到全年。

### 2. 同属金属不等于同一供给曲线

  铜是用途广泛的精炼金属，矿山中断、品位和库存都能造成阶段性紧张；铁矿石是高度依赖钢铁需求的大宗原料，2014 年低成本巨型矿山扩产形成更强的供给压力。因此铁矿石的下跌幅度显著超过铜是可以在事前提出的结构性假设。

### 3. 政策冲击可能确认趋势，而非创造趋势

  OPEC 不减产之所以影响巨大，是因为它发生在非 OPEC 供给增加、需求预期走弱、库存开始累积的背景中。如果没有这些先行条件，同样一句会议公告未必产生相同价格后果。

### 4. 低价会反噬未来供给，但不是即时开关

  钻井许可和资本开支可以快速下降，已经完工或接近投产的项目却可能继续增加产量。模型需要分别讨论投资、钻机、完井和实际产量，不能从“价格低于边际成本”直接推导当月供给骤减。

## 三、建议的因果链

```text
高价持续
  → 勘探、矿山、致密油和基础设施投资增加
  → 若干年后新增产能集中释放
  → 同期需求增速下降或库存上升
  → 价格缓慢转弱
  → 地缘/天气短期反弹暂时遮蔽过剩
  → 政策不托底或需求进一步下修
  → 价格加速下跌
  → 投资与钻井削减
  → 未来供给增速放缓，形成下一阶段反馈
```

  这条链只是候选机制。被测系统应允许反证，例如供应中断扩大、需求刺激超预期、生产者重新协调减产、极端天气造成粮食减产，而不是把任何下跌都解释成同一“超级周期”。
