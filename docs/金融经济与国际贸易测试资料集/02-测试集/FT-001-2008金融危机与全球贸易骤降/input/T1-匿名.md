# T1 匿名增量输入：阶段 1

> 伪日期截止到 2000-11-17 23:59:59 UTC。这是阶段 0 后新增的信息。

## 新发生的金融冲击

  一家具有全球影响的大型证券交易商失败。随后银行间和短期融资市场严重紧张，多个经济体采取流动性支持、担保和资本注入措施。此处不预告目标年度结果。

## S05：先进经济体 A 的新一轮银行信贷调查

- 大中型企业贷款标准净收紧比例升至 83.6%，小企业升至 74.5%。
- 商业地产贷款标准净收紧比例约 98%；住房和消费信贷也广泛收紧。
- 银行普遍报告风险容忍度下降、经济前景恶化和资金成本上升。
- 企业与家庭信贷需求继续减弱。

## S06：多边展望机构 X 的更新

- 目标年度世界产出增长预测降至 2.2%。
- 下修理由包括金融去杠杆、资产价格下跌、信心下降和先进经济体衰退。
- 该机构预计先进经济体目标年度整体收缩，但新兴经济体仍保持正增长。

## S07：先进经济体 A 的专业预测调查

- 目标年度实际 GDP 年增长中位预测为 -0.2%。
- 未来五个季度的年化中位预测依次为 -2.9%、-1.1%、0.8%、0.9%、2.3%。
- 这些数值代表当时专业共识，不是后来实际值。

## 本轮需要重新判断

- 金融冲击是否已经足以令目标年度世界贸易量负增长。
- 贸易降幅超过 5% 是否仍只是低概率尾部情景。
- 需求、融资、库存和跨境供应链中，哪些机制应提高权重。
