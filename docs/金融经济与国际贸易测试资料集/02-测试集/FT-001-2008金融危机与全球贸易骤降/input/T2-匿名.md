# T2 匿名增量输入：阶段 2

> 伪日期截止到 2001-01-28 23:59:59 UTC。目标年度全年结果仍未知。

## S08：国际银行观察机构 B 的季度回顾

- 大型证券交易商失败后，全球金融市场一度近乎冻结，货币市场和信用市场功能严重受损。
- 各国推出非常规流动性支持、担保、资本注入和降息措施，但资产负债表收缩仍在继续。
- 市场压力已经扩散到银行、企业融资和跨境资本流动。

## S09：国际发展机构 Y 的全球展望

- 该机构预测目标年度世界 GDP 增长 0.9%，高收入经济体增长 -0.1%。
- 预测目标年度世界贸易量下降 2.1%，为约二十七年来首次收缩。
- 报告将信贷紧缩、投资放缓、商品价格下跌和先进经济体需求减弱列为主要背景。
- 这是预测，不是实际结果。

## S10：多边展望机构 X 的再次更新

- 该机构预测目标年度世界产出按购买力平价口径增长 0.5%，按市场汇率口径为 -0.6%。
- 预测目标年度世界货物与服务贸易量下降 2.8%。
- 该机构认为金融部门与实体经济之间的负反馈仍在增强。
- 该贸易指标包含货物与服务，测试主目标只看世界货物贸易量，两者口径不同。

## 本轮需要重新判断

- 官方预测已经转为负增长，但是否仍低估同步衰退的非线性影响。
- 贸易对 GDP 的下滑弹性是否会因耐用品、投资品、库存和供应链而显著放大。
- 贸易融资与保护主义是主因、放大因素，还是次要风险。
