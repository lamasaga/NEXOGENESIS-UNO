# FT-001：2008 年金融危机与全球贸易骤降

  本测试检查系统能否从金融压力出发，逐步判断全球贸易风险，并在 T1、T2 新信息到来后合理更新。它不是“解释 2008 年发生了什么”的知识问答。

## 被测能力

- 从信贷收紧推断实体经济与跨境贸易的传导风险。
- 给出概率、点预测和区间，而不是只写方向性散文。
- 新证据到来后调整判断，并说明调整幅度。
- 比较需求、商品构成、供应链、库存、贸易融资和保护主义等竞争解释。
- 标记数据事实、机构预测和自己的推断。

## 运行纪律

  评测程序应读取 `case.json`，每次只开放当前变体当前时点的 `visible_files`。不要让被测 Agent 浏览测试项目目录，否则它可以直接读到评分答案。

  `named` 是具名历史回放；`anonymous` 使用一致的主体替换和相对时间，但保留经济结构。两种变体要用相同模型、温度、token 上限、工具权限和起始知识库。

## 文件说明

| 文件 | 用途 |
|---|---|
| `case.json` | 案例元数据、时间点和文件白名单 |
| `source-manifest.json` | 每条输入的时间与来源记录 |
| `questions.jsonl` | 各时点要回答的问题 |
| `output-schema.json` | 机器可读输出格式 |
| `input/` | 具名与匿名输入包 |
| `fixture/` | C、D 组使用的小型冻结知识图谱与时点清单 |
| `evaluator/` | 隐藏结果和人工评分规则，禁止被测模型读取 |

## 运行后最少保存

- 模型、版本、参数、系统提示与工具权限。
- 每个时点的原始输出和解析后 JSON。
- 实际开放的文件列表。
- 工具调用、token、耗时和错误。
- T0→T1、T1→T2 的概率变化。

  当前数据集可用于人工跑通、输出契约验证和冻结图谱准备。确定性评分程序已经可用，但自动临时装载、模型调用、目录隔离和 A～D 批量运行仍未实现。单一案例不足以评估总体校准；Brier、区间覆盖等统计指标要在多个案例上汇总。
