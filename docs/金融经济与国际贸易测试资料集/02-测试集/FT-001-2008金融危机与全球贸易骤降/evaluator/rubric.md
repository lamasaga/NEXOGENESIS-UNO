# FT-001 评分规则

> 本文件只供评分程序和人工评审使用，禁止提供给被测模型。

## 一、先做有效性检查

  任一时点若明确使用该时点之后的具体事件、实际数值或事后研究，该时点标记为 `leakage_fail`。可以继续保存输出供诊断，但不把该输出与正常历史回放结果混合汇总。

  JSON 解析失败、概率超出 0—1、50% 区间不包含点预测、90% 区间窄于 50% 区间、三个场景概率之和不在 0.98—1.02 之间，均记录为契约错误。契约错误与判断错误分开统计。

## 二、自动计算项

### 2.1 二元事件

  两个事件的实际结果都为 1。每个时点分别计算：

```text
Brier = (p - 1)^2
```

  单题 Brier 不能证明概率校准，只用于比较相同案例下的具名/匿名、裸模型/DSH 和不同版本。T0 直接给出极端高概率可能来自历史记忆，因此必须结合匿名差异和证据质量判断。

### 2.2 数值预测

  0.1.0 使用 WTO 首次完整估计 `-12.2%` 作为参考值：

```text
absolute_error = abs(point - (-12.2))
interval_50_hit = -12.2 是否位于 interval_50
interval_90_hit = -12.2 是否位于 interval_90
```

  T0、T1、T2 都保存误差，但重点观察随信息增加是否改善。不要因为 T0 偶然命中而自动认为分析更好，也不要把 IMF 的货物与服务口径和 WTO 货物口径视为同一条修订序列。

## 三、人工评分项

  每项 0—4 分，总计 24 分。评审应写一句依据，不只给数字。

| 项目 | 0 分 | 2 分 | 4 分 |
|---|---|---|---|
| 时间边界 | 明显使用未来事实 | 大体守界但口径或来源时间含混 | 严格区分当时事实、预测和推断 |
| 传导链 | 只有“危机会令贸易下降” | 提到信贷、需求和贸易但连接松散 | 清楚说明资产负债表→信贷/财富/投资→耐用品与资本品需求→贸易 |
| 竞争解释 | 单因果断言 | 罗列多因素但不比较 | 比较需求、构成、供应链、库存、融资和政策，并说明主次 |
| 反证意识 | 没有反证 | 有笼统保留 | 为主要机制给出能使其降权的具体观察信号 |
| 更新适度 | 不更新或跟随新闻极端跳变 | 方向正确但幅度理由不足 | 概率变化与证据强度相称，并指出仍未知部分 |
| 口径与尺度 | 混用 GDP、贸易额和贸易量 | 能区分部分指标 | 明确区分货物/服务、名义/实际、季度/全年和短期/结构机制 |

## 四、机制题的参考边界

  高分回答不必与事后文献逐字一致，但应满足以下边界：

- 全球最终需求骤降应处于主要机制之一。
- 耐用品和投资品构成、全球供应链或同步收缩至少有一项被识别为放大机制。
- 贸易融资可以被赋予重要权重，但若断言它是唯一主因，需要当时证据和反证条件。
- 保护主义可以列为风险，不应在没有证据时被写成已经主导全球收缩。
- 允许模型在 T0 给出较低危机概率；重点是风险是否被表达、证据是否充分、后续是否合理更新。

## 五、建议的对比报告

| 对比 | 主要看什么 |
|---|---|
| 具名 vs 匿名 | 历史名称和日期带来的记忆增益 |
| M0 裸模型 vs M1 固定数据包 | 当时材料本身的增益 |
| M1 vs DSH | 检索、知识图谱和循环是否改善证据组织与更新 |
| DSH 稳定版 vs 候选版 | 新 TM/OPS 是否改善结果而没有增加泄漏、成本或无效调用 |

  当前只有一个案例，不生成“总体智能分”。应同时报告契约错误、泄漏、两个 Brier、数值误差、区间命中、人工六项评分、token、耗时和工具调用数。
