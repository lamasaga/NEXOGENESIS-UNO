# T0 匿名输入：2000-06-30

> 这是经过时间与实体替换的测试版本。预测目标是区域国家 C1、C2、C3、C4 在 2001 年的经济表现。不要尝试识别真实历史事件，只依据本文件和以后逐轮开放的信息判断。

## 任务边界

  你必须逐国判断，不能把四国写成同质的“区域经济体”。其他经济体只可作为外部环境，不是预测对象。所有增长预测均是当时可见的专业判断，不是后来结果。

## S01：危机前区域共识

- 一家区域开发机构预计，包含四国在内的区域经济体 2000 年增长约 7.7%、2001 年约 8.1%。
- 全球贸易环境和主要先进经济体增长总体被视为支持区域扩张。
- 报告承认金融体系和外部失衡需要关注，但基准情景不是区域衰退。

  来源 ID：S01。

## S03：国际银行研究机构 2000 年 6 月脆弱性资料

### 信贷规模与扩张

| 国家 | 1999 年私人信贷/GDP | 2000 年私人信贷增长相对 GDP 增长 |
|---|---:|---:|
| C1 | 88.7% | 5.8 个百分点 |
| C2 | 49.1% | 5.7 个百分点 |
| C3 | 76.9% | 13.1 个百分点 |
| C4 | 39.3% | 31.5 个百分点 |

  第二列表示私人信贷增长率超过 GDP 增长率的幅度，不是信贷余额占 GDP。

### 国家观察

- C1：出口停滞、房地产下滑、股价下跌和金融机构脆弱并存。高利率既被用于维持资本流入，也会加重金融体系压力；汇率继续紧密跟随美元主导的一篮子货币。
- C2：此前增长和资本流入强劲，通胀与经常账户压力促使政策收紧；上年本币实际升值约 7%。
- C3：信贷、投资和房地产活动较强，外部失衡仍大；政策已经收紧，但资本流入限制了货币政策效果。
- C4：上年增长接近 6%，经常账户赤字约为 GDP 的 4%；进口增长快于出口，信贷在数年内大约翻倍，部分由资本流入推动。

### 国际融资

- 上年国际银行对 C1 的新增贷款明显减少，但对 C2、C3 和 C4 的贷款仍在增加。
- 区域借款人增加债券融资，有助于分散来源，但短期银行债务占比仍高；C1 的短期银行债务占比可达约 70%。
- 研究机构已把短期融资、汇率防守和金融体系质量联系起来，但没有预测区域性深度衰退。

  来源 ID：S03。
