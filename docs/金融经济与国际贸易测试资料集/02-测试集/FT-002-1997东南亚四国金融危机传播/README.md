# FT-002：1997 年东南亚四国金融危机传播

  本测试要求系统在一个有限区域内比较泰国、印度尼西亚、马来西亚和菲律宾。目标不是识别“亚洲金融危机”这个历史名称，而是从逐步出现的信息判断四国的 1998 年产出、汇率、外部账户和相对严重程度。

## 与 FT-001 的区别

| FT-001 | FT-002 |
|---|---|
| 一个全球贸易总量目标 | 四个国家的多个相关目标 |
| 重点是全球金融到贸易的传导 | 重点是区域传染和国家差异 |
| 一个数值结果 | 产出、汇率、经常账户和严重程度排序 |

## 运行纪律

  每次只开放 `case.json` 中当前变体和时点的 `visible_files`，并附加对应问题文件与 `output-schema.json`。不得允许 Agent 浏览 `evaluator/`、调研资料或源数据 CSV。

  T1、T2 必须建立在前一时点保存的输出上。模型不能悄悄重写 T0；评分器需要比较每个国家概率和区间如何更新。

## 可见与隐藏文件

| 文件 | 被测模型权限 |
|---|---|
| `input/` 当前时点白名单 | 可读 |
| `questions*.jsonl` 对应变体 | 可读 |
| `output-schema.json` | 可读 |
| `source-manifest.json` | 运行器读取，不直接提供给模型 |
| `evaluator/` | 禁止 |
| `01-调研资料/1997东南亚四国金融危机传播/` | 禁止 |

## 最小产物

- 三个时点的原始输出和有效 JSON。
- 四国收缩、汇率贬值和经常账户转盈概率。
- 四国 GDP 点预测、50% 和 90% 区间。
- 严重程度排序及排序变化。
- 每轮证据、反证、下一步信号和工具轨迹。
- 具名与匿名版本之间的差异。

  本案例已具备人工运行、冻结图谱和确定性评分条件；DSH 还没有自动临时装载、模型调用、目录隔离和 A～D 批量运行器。
