## S01：结构信息

- 原油过去三年价格稳定在约 105 美元附近，但美国致密油和加拿大油砂等非常规供给持续增长。世界银行认为长期实际油价可能因新增供给、效率提升和替代而缓慢下降。
- 2013 年部分产油国供应中断和地缘风险支撑油价；产油国组织仍被市场视为可能通过调整产量稳定价格。
- 金属价格在金融危机后强劲反弹，高价推动矿业投资和新增产能。金属价格从 2011 年高位回落，未来取决于新供给投产和中国增长。
- 中国约占全球精炼金属消费的 45%，使铜和其他金属对同一需求中心高度敏感，但不同矿种的新增产能并不相同。
- 小麦生产可在下一个种植季调整，但天气、单产、库存和贸易政策会造成年度波动；不能直接套用矿业投资周期。
