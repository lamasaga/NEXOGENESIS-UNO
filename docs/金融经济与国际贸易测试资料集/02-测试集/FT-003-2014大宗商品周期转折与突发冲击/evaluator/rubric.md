# FT-003 评分规则

  本规则把可计算的结果准确度与人工判断质量分开记录。不要把所有维度压成一个“智能分”；同一回答可能方向准确但理由错误，也可能机制判断良好但点估计偏离。

## 一、运行前检查

- 每个时点只开放 `case.json` 所列输入、对应问题和 `output-schema.json`。
- 被测系统不得读取本目录、调研资料或结果数据，也不得联网检索。
- 匿名版应先于具名版运行，并使用新的会话或清空可检索记忆。
- 匿名回答若出现 `anonymization-map.json` 中的禁用词，记为泄漏风险，人工复核后决定是否整轮作废。
- 输出必须通过 JSON Schema；四个 `drawdown_rank` 必须恰好构成 1、2、3、4；三种情景概率之和容差为 ±0.01。

## 二、自动记录项

### 1. 二元事件

  对每种商品分别计算“均价下降至少 20%”和“低点位于下半年”的 Brier 分数；对两个组合事件也分别计算。Brier 越低越好，应保留每个时点、每个商品的明细。

### 2. 价格与区间

- 点估计：记录绝对百分比误差 `abs(predicted - actual) / actual`。
- 50%与 90%区间：分别记录实际值是否落入。
- 另记区间宽度，防止仅靠极宽区间获得覆盖。

  年度均价使用 O04 的冻结结果；最低价月份使用 O05 的月度序列。两种版本有后续修订和取整差异，评分器不得用 O05 的月均值覆盖 O04 的年度答案。

### 3. 跌幅排序

  用六个商品对的相对顺序计算正确比例。真实顺序为 K1、K3、K4、K2。若四个名次重复或缺失，则该项无效。

### 4. 连续更新

  保存 T0—T3 的概率与点估计变化。此项不预设“每轮都必须向真实结果移动”；重点检查新增证据是否真的触发了与其强度相称的更新。

## 三、人工评分（每项 0—4）

| 维度 | 0 分 | 2 分 | 4 分 |
|---|---|---|---|
| 时间边界 | 使用未来结果或匿名泄漏 | 偶有越界暗示但主体同期 | 严格只用当时材料，并区分事实与预测 |
| 周期分层 | 把周期当固定钟摆或只看价格 | 能列长中短但联系较弱 | 清楚说明产能、库存需求、事件的机制、方向和期限 |
| 商品差异 | 把四类商品当一个指数 | 能说出若干差异 | 能解释铜与铁矿石、能源与粮食为何响应不同 |
| 突发事件 | 把事件当全部原因或完全忽略 | 承认事件但基准判断不清 | 区分事件的即时效应、确认作用和长期基准变化 |
| 滞后推理 | 默认价格立即关闭供给 | 提到滞后但未展开 | 解释投资、钻井、矿山、种植与实际产量的不同滞后 |
| 反证意识 | 只有单向叙事 | 有笼统风险提示 | 对关键判断给出具体反证、触发条件与替代解释 |
| 更新相称性 | 各轮复制或剧烈追涨杀跌 | 有更新但理由不完整 | 更新方向与幅度对应新增证据，并说明保持不变的部分 |

## 四、阅卷时应寻找的关键认识

- 高价会引出投资，新增供给常在数年后集中投放；这是一种机制，不是固定长度的价格周期。
- 原油供应增长、需求弱于预期和库存增加在生产组织决定前已经出现；11 月决定加强并确认了调整压力，但不是四类商品下跌的唯一原因。
- 低价可以立即压低钻井和资本开支，而已完工项目、既有井和在途扩产仍令当年产量增长。
- 铜和铁矿石共享工业需求风险，但铁矿石更受低成本大型矿山集中扩产和钢铁需求影响，因此两者不能用一个“金属周期”替代。
- 小麦的天气冲击较短，产量、库存和库存消费比能在一个种植年度内改变其持续性。
- 美元、全球增长和风险偏好可构成共同因素，但必须同时保留商品特有供需约束。

## 五、明显错误

- 声称商品周期按固定年数自动反转，而没有供需机制。
- 用 T3 的生产组织决定解释早已发生的铁矿石和铜供给变化。
- 看到小麦短期上涨就忽略产量与库存恢复，或看到最终下跌便否认当时天气风险真实存在。
- 把同期机构预测当事实，或因为事后预测错误而认为当时不应使用它。
- 在没有证据时精确断言所有商品会在同一月份见底。

## 六、具名版与匿名版比较

  两次测试应分别保存，不取较好的一次覆盖较差结果。若具名版明显优于匿名版，检查是否依赖历史记忆；若匿名版机制更清楚而具名版出现“背答案”，应在结论中明确记录。两版在方向、排序和更新逻辑上接近，才更能说明系统掌握了可迁移的周期分析方法。
