# FT-003：2014 年大宗商品周期转折与突发冲击

  本案例要求系统连续判断原油、铜、铁矿石和小麦在 2015 年的价格方向与路径。测试重点是区分长期产能和需求结构、中期库存与商业周期、短期地缘天气和政策事件，而不是复述“商品超级周期结束”。

## 四种商品

| 编号 | 具名版 | 主要差异 |
|---|---|---|
| K1 | 世界银行综合原油 | 产油国协调、致密油、库存和地缘风险 |
| K2 | 铜 | 工业需求集中、矿山建设慢、供应中断和库存 |
| K3 | 铁矿石 | 钢铁需求和低成本大型矿山集中投产 |
| K4 | 美国硬红冬小麦 | 年度种植、天气、库存消费比和贸易政策 |

## 运行纪律

  首次运行建议使用匿名版。每次只开放 `case.json` 当前时点列出的文件，并提供相应问题与 `output-schema.json`。T1—T3 必须在同一会话中继续，但不得改写已经保存的旧轮输出。

  被测 Agent 不得读取 `evaluator/`、调研资料和研究数据 CSV，也不得联网搜索。具名版可以使用材料中出现的机构和商品名称，但不能使用截止时间之后的历史结果。

## 评测重点

- 能否区分价格动量和供需结构。
- 能否说明不同层次信号的作用方向、滞后和反证。
- 能否区分铜和铁矿石，而不是笼统预测“金属”。
- 能否把 OPEC 决策理解为确认或加速既有供给压力，而非唯一原因。
- 能否识别低价先影响投资和钻井、再滞后影响产量。
- 能否在 T0—T3 逐步更新，而不是一开始就背出最终结果。

  本案例可人工运行，并已具备冻结图谱、共同输出外壳和跨字段确定性检查。DSH 尚未实现自动临时装载、模型调用、目录隔离和 A～D 批量运行器。
