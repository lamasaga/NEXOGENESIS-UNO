# FT-004 人工评分表

  每项 0～2 分。时间越界、虚构证据或读取 evaluator 直接判本轮无效，不用综合分抵消。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 风险与事件区分 | 把市场损失或邻国危机直接当作美国衰退 | 能口头区分，但概率和叙述仍混杂 | 分别判断压力、渠道、阈值和目标事件 |
| 机制与滞后 | 只列风险词 | 有渠道但缺少时间或中间条件 | 住房、耐用品、库存、信用、贸易与政策反应有清晰条件 |
| 反证 | 不找反证 | 提到韧性但不改变判断 | 反证会限制结论并改变概率或下一步 |
| 情景校准 | 单一路径或三情景不合计为 1 | 有三情景但条件重叠 | 情景互斥、概率合计为 1、转换信号明确 |
| 更新幅度 | 每轮不变或见一条消息剧烈翻转 | 能更新但理由含糊 | 更新与证据强度相称并保留上一轮记录 |
| 图谱贡献 | OPS 无关、重复或答案无证据 | 找到相关卡但关系没有增益 | 图路径或比较带来文本包不易发现的反证或机制 |
| 可读性 | 只有内部编号和日志 | 能读懂结论但不知为何变化 | 清楚说明改变、未改变、理由和下一观察项 |

## 成对比较

  比较 C 与 D 时，评分者先隐藏组别，只看答案与经脱敏的证据轨迹。若 D 只是多写术语或多调用工具而没有改善证据、校准或成本，应判平局或更差。
