# FT-004：1994—1995 年美国货币紧缩与软着陆

  本案例测试系统能否在风险信号密集时避免“逢风险必报危机”。1994 年快速加息引发债券损失，随后墨西哥发生货币危机，美国经济也确实放缓；但 1995 年美国没有进入衰退。

## 运行方法

1. 首次使用匿名版；每轮只开放 `case.json` 所列的当前及以前输入。
2. 每个检查点保存一次符合 `output-schema.json` 的完整答案，不覆盖前一轮。
3. 人工固定材料测试可直接使用 `input/`；OPS × TM × Skill 测试必须按 `fixture/manifest.json` 建立临时知识体。
4. 被测 Agent 不得读取 `evaluator/`、调研资料、未来时点文件或互联网。
5. 同一配置至少重复三次；A～D 组固定模型、参数、快照和近似预算。

## 主要评价

- 是否区分资产价格损失、邻国危机、经济放缓和美国衰退。
- 是否说明住房、耐用品、库存、信用与外需的传导条件及滞后。
- 是否给软着陆、硬着陆和再通胀情景分配概率，而不是只讲单一路径。
- 新 Observation 是否真正改变下一轮概率和行动，而不是每轮重写同一段话。
- C、D 组是否真实调用了有用的 GraphOps；D 组的 TM 是否比 C 组带来额外而稳定的改善。

## 当前可用程度

  固定材料部分可以人工顺序运行。`fixture/` 已提供小型冻结知识体和可见性清单，跨字段确定性检查也已可用；DSH 的自动临时装载、匿名变换、Episode 评分和 A～D 批量运行器尚未实现。完成运行器前，不应宣称本案例已经自动分离测出了 OPS、TM 和 Skill 的贡献。
