# T3 新增输入：1995-03-31

## 传导证据

  3 月地区调查显示，住房活动已经因利率上升而放缓，但许多地区的制造、就业和消费活动仍有韧性。市场和企业联系人对前景分成“软着陆”与“可能衰退”两派，尚无一致结论。[S08]

  刚公开的 2 月会议记录预计 1995 年实际 GDP 增长约 2%～3%，失业率约 5.5%，同时承认住房、耐用品、库存削减和墨西哥贸易冲击可能让增长明显放慢。部分委员担心继续加息会放大下行风险，但全体仍支持当次行动。[S09]

## 最终时点任务

  这是预测结果揭晓前的最后检查点。请结合前几轮记录更新概率，不得使用 1995 年 7 月后的政策和全年结果。软着陆并不意味着没有债券损失或局部收缩；硬着陆也不能只凭一个先行指标确认。
