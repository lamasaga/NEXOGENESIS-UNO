# T0 输入：第一年 03-25

## 已知政策与经济情况

  经济体 A 的货币当局在第一年 2 月把短期政策利率从约 3% 提高到 3.25%，是近五年来首次收紧。声明把它描述为小幅、预防性的行动，目的是在扩张延续时避免通胀压力积累。[S01]

  刚公开的会议记录显示，上一年末经济活动较强，年初仍有增长迹象；工业生产、就业和家庭支出具有韧性。通胀表现仍较好，但决策者担心经济接近潜在能力后，价格压力可能滞后出现。[S02]

## 当前分叉

- 软着陆：提前、小步收紧压低未来通胀，增长回到可持续速度。
- 硬着陆：利率对住房、耐用品、库存与融资的滞后作用被低估，随后造成衰退。
- 再通胀：需求持续强于供给，当前收紧不足，未来需要更大幅度行动。

  现在没有第一年全年数据，也没有下一年结果。请只依据本文件作出概率判断。
