# T1 新增输入：1994-09-30

## 政策更新

  3 月和 4 月各加息 25 个基点，5 月加息 50 个基点；8 月 16 日再次加息 50 个基点，目标达到 4.75%。8 月声明称经济持续强劲、资源利用率高，并认为本次行动至少暂时足以应对通胀风险。[S03]

## 实体与金融信号

  8 月会议记录显示，就业和工业生产继续增长，企业设备投资较强，失业率约 6.1%；经济增速可能较此前高位有所放缓，但仍相当可观。[S04]

  长期利率上升和债券价格下跌已经造成持有者损失。它说明金融条件收紧，但本材料没有给出银行信用全面冻结、企业融资中断或总产出收缩的证据。分析时应把市场损失与实体衰退分开。
