# T0 输入：1994-03-25

## 已知政策与经济情况

  美联储在 1994 年 2 月 4 日把联邦基金利率目标从约 3% 提高到 3.25%，这是 1989 年以来首次收紧。声明把它描述为小幅、预防性的行动，目的是在经济扩张延续时避免通胀压力积累。[S01]

  刚公开的 2 月会议记录显示，1993 年末经济活动较强，1994 年初仍有增长迹象；工业生产、就业和家庭支出具有韧性。通胀表现仍较好，但决策者担心经济接近潜在能力后，价格压力可能滞后出现。[S02]

## 当前分叉

- 软着陆：提前、小步收紧压低未来通胀，增长回到可持续速度。
- 硬着陆：利率对住房、耐用品、库存与融资的滞后作用被低估，随后造成衰退。
- 再通胀：需求持续强于供给，当前收紧不足，未来需要更大幅度行动。
