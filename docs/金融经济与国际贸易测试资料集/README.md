# 金融经济与国际贸易测试资料集

  本目录保存可重复运行的历史情景测试。当前包含四个互补案例：2008—2009 年全球金融冲击与贸易骤降、1997 年东南亚四国的区域传染、2014 年四类大宗商品在长短周期和突发事件叠加下的价格转折，以及 1994—1995 年美国快速加息后“压力发生但衰退未发生”的软着陆负例。

  本目录遵循《金融、经济与国际贸易历史情景回放评测框架》。四个案例都可由人工按时间顺序运行，并已具备共同输出外壳、A～D 执行配置、冻结图谱 fixture、预期证据集合和跨字段确定性检查。自动装载、模型调用、权限隔离和批量实验运行器尚未实现。

## 目录分工

| 目录 | 用途 | 是否可给被测模型读取 |
|---|---|---|
| `01-调研资料/` | 完整调研、事后结果、来源判断与设计理由 | 否 |
| `02-测试集/` | 截止各观察时点可见的输入、问题、输出格式和评分答案 | 仅按 `case.json` 白名单开放 |

  调研资料与测试输入必须保持分离。运行测试时，不要把整个目录交给 Agent；应只挂载 `case.json` 中当前变体和当前时间点列出的文件。`evaluator/` 只能由评分程序或人工评审读取。

## 最小运行方法

1. 选择 `named` 或 `anonymous` 变体。
2. 只向模型提供 T0 输入，要求回答 `questions.jsonl` 中 `checkpoint=T0` 的问题，并按 `output-schema.json` 输出。
3. 保存结果后依次开放该案例剩余时点；每次都要求模型说明概率为何变化。
4. 结束后由评审者读取 `evaluator/outcomes.json` 与 `evaluator/rubric.md` 评分。
5. 不允许模型读取 `01-调研资料/` 或 `evaluator/`。

  四套答案共同要求 `previous_checkpoint`、`evidence_anchors`、`update_delta` 和 `limitations`；领域预测字段仍按各案例自己的 `output-schema.json`。运行前可执行 `node tools/eval/check-cases.mjs` 检查案例契约，单次答案可用 `node tools/eval/score-response.mjs` 检查跨字段规则并计算已有量化指标。

  匿名版只能降低事件名称带来的直接提示，无法消除模型预训练中的历史记忆。它适合比较同一模型、同一版本的相对差异，不应被解释为纯粹的真实预测能力。
