# UNO 请求上下文治理

核对日期：2026-09-16。范围：UNO 的编译与建构原生会话，包括恢复历史任务；不改变保存的业务协议，不改普通对话路线。治理版本：`uno-request-context-v1`。

## 问题与处理

过去原生会话不断保存新的任务快照，每次请求又派生完整历史；“这个快照替代旧快照”只是写给模型的文字，并没有移除旧输入。失败的长参数、重复工具正文也随历史反复外发。已有首包 48,000 字节和阶段请求次数限制都不是完整请求预算。

现在将持久记录与模型输入分开：事件、工具执行结果、来源和草稿仍按原逻辑保存；每次请求由原记录确定性生成一个只读视图。不调用模型做摘要，不删除文件，不通过首尾裁剪破坏 JSON。

| 内容 | 当前规则 |
|---|---|
| 任务进度 | 按原生插件来源、section 名及完整渲染结构识别；同任务只保留最新 UNO 状态。其他独有动态 section、改变的策略及用户文本保留。 |
| 失败大参数 | 只处理确定在执行前拒绝、且参数在后续直接调用中完整保留的重复部分；保留操作身份、参数哈希、原错误与后续调用定位。未知执行结果、有收据、部分成功批次及最新一轮保持原样。 |
| 重复读取 | 工具、参数和完整返回载荷都相同时，只留一份完整结果。版本、区间、来源、元数据任何差异均不合并。被省略处保留后续调用定位。 |
| 唯一证据 | 原文、卡片、关键反证和首个证据包不因“历史已读”被删；阅读台账不作为当前上下文可见的替代证明。 |
| 原生回放 | 改动旧 assistant 参数时清除该条不再匹配的不透明 replayState；含签名推理或其他未知块的 assistant 保持原样。工具调用 ID 与回执配对不变。 |
| 整体预算 | 完整运行时输入上限 128,000 UTF-8 字节，包含系统规则、工具定义、消息和保守计入的不透明回放；实际 HTTP 正文在发送前再执行同一上限，覆盖 SDK 格式及展开附件。不是 128,000 Token。 |
| 超限 | 在网络发送与请求账本扣减前拒绝，明确暂停并保留成果。明确恢复后建立新的当前阶段上下文；累计请求额度不重置。重新开始作者上下文时清空其可见阅读凭据，旧收据、草稿、去向和日志保留，需精确证据时重新交付。 |
| 诊断 | 提示词查看器显示治理前后字节、移除类别和估计 Token；Kimi 已能记录发送前真实正文。推理块、不透明回放、图片二进制、请求头与密钥不作为诊断内容保存；历史诊断读取也做同样过滤。 |

128,000 字节是当前可验证的资源上限，并非模型窗口大小或最优阈值。Token 仅提供显式估计，供应商返回的实际输入、缓存与输出用量仍单独保存。图片展开后可能触及上限，此时暂停而不默默丢图。

## 运行时接线

- `packages/nexogenesis-tools/lib/uno/request-context.js`：纯消息投影、完整输入与最终正文预算、请求统计。
- `native-request-context.js`：限定 UNO compile preset 的 DSH rc.6 接缝。在 agent/pre-step 安装只读 deriveMessages 视图，在 buildRequest 计量完整输入；不篡改冻结后的 llm/stream。原生 invariant、Inspector、证据交付观察器和适配器看到同一视图。
- `agent.js`：按不可变会话归属绑定知识库，写入无正文的治理指标。
- `presets/uno-compile/agent.cordis.yml`：移除编译、建构中的原生模型压缩，防止它先依据未精简历史再花模型请求做摘要；普通对话 preset 不变。
- `model-adapter.js`、`native-kimi-budget.js`：完整外发正文的最后一道检查；原生 SDK 吞错、重试或等待凭据后卸载均不能绕过。
- `uno-workflow-v3.js`、`uno-orchestration.js`：保存明确暂停原因，恢复当前阶段；兼容全局/本地 LlmError 类不一致时原生错误码变成 UNKNOWN 的情况。

DSH rc.6 没有正式的可变请求 middleware：llm/stream 是只读接口，next 不接受替代参数。本实现使用限定实例的方法包装，核对接口形状，卸载恢复原方法；发现不兼容则停止发送。升级原生依赖必须重跑原生测试，不能只依赖健康标记。

## 边界与撤回

本次解决请求组织、冗余、可观测性和预算边界；未证明新卡片数量、知识质量或实际 Token 成本达到目标。旧失败草稿中的来源修订问题及旧成果复用另行处理，不借治理把它们标成已解决。普通对话的检索和回答路线不变。

若撤回，先暂停相关任务，按本次文件备份整体恢复接线、适配器、专用 preset 及页面，再构建并重启空闲服务；保留所有知识、草稿、原始事件和账本。不要只取消预算检查或把旧任务的协议标记改成新版。不要用恢复原生模型压缩来掩盖缺少预算控制。
