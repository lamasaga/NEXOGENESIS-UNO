# UNO 语音输入

语音输入把口述转成可编辑文字，不自动发送消息、创建任务或调用聊天模型。它适合输入较长问题，发送前仍应检查人名、数字、否定词和专业术语。

## 安装本地识别

识别使用 faster-whisper small 的 CPU int8 模型，普通话优先，支持句中英文缩写；结果经 OpenCC 转为简体中文，不由聊天模型改写。

首次安装需要 Python 3.10–3.12 与网络。在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\setup-speech.ps1
```

默认使用命令行中的 `python`。需要指定解释器时，加上 `-Python "C:\Python312\python.exe"`，路径应换成实际安装位置；已有模型可以通过 `-ModelPath "D:\models\faster-whisper-small"` 指定。

脚本在项目自己的 `.nexogenesis/speech/venv/` 中安装依赖，不修改系统 Python；优先复用匹配的模型缓存，否则下载固定模型版本。模型真实加载成功后才保存配置。安装后重新启动 UNO 并刷新页面。

干净发行包包含识别代码和安装脚本，不携带本机模型、配置或虚拟环境。仅下载程序而未安装模型时，语音识别尚不可用。

## 录音和发送

1. 点击输入栏发送按钮旁的麦克风图标，按浏览器提示允许麦克风权限。
2. 正常说话，录音时可查看时长。
3. 点击方形停止图标开始转写；也可点击取消放弃。
4. 识别文字追加到当前草稿末尾，检查并修改后再发送。

单次最长 60 秒，到时进入转写。录音或转写期间可以取消；切换对话也会取消，保留原有草稿。识别结果不会覆盖你在等待期间对草稿做的编辑；没有清晰语音时会提示重新录音。

## 隐私与资源

录音发送到正在运行 UNO 的本机服务，在内存中处理，不上传外部语音识别服务，也不保存到知识库或录音日志。识别运行时使用本地模型，不自动下载。

后台一次处理一段录音，取消会终止该段计算。模型按需加载，空闲 5 分钟后释放；首次加载通常比后续识别更慢，实际速度取决于电脑和录音长度。

本地转写与模型对话是两件事：点击发送之后，文字仍可能交给你配置的在线聊天模型。

## 使用条件与限制

通过本机 `http://127.0.0.1:3093` 使用具备麦克风权限的浏览器。若无法录音，检查站点权限、输入设备、设备占用和系统麦克风权限；若能录音却无法识别，检查安装是否完成及后台错误提示。

当前服务面向本机使用，不提供手机远程语音访问的完整部署方案。不同浏览器和实际麦克风表现需要在设备上核验。

识别受口音、噪声和说话方式影响，不保证逐字准确。该功能不是实时字幕、自动翻译或语音播报；转写成功也不表示消息已经发送。
