# GraphOps 思考循环测试提示词组合

> 日期：2026-08-19
> 目标：验证思维体「先定位 → 沿论证边走 → 冲突/类比 → 记债 → 审批写入」的思考循环（v2.2 移植版），而不是「一次检索就答」。
> 前置：设置面板填入 `DEEPSEEK_API_KEY` → `start-nexogenesis.cmd` → http://127.0.0.1:3083；测试时保持图谱视图可见（观察动效）。
> 工具面：graph_search / graph_walk(mode=neighbors|conflicts) / graph_members / graph_analogize / read_card(slots) / graph_note / propose_write；M5：plan-mode / goal / subagent。

---

## 怎么算「通过了」（评价口径）

| 观察点 | 好（通过） | 坏（未通过） |
|---|---|---|
| 工具序列 | 定位(search)→沿边(walk)→精读(read_card)→必要时类比/冲突→综合 | 一次 retrieve/graph_search 就长篇作答，无后续动作 |
| channel 意识 | 区分 lexical/membership/argument/analogical，不把成员列表当论证邻居 | 混用后无视 `note`/`misuse` 提示 |
| 多跳 | walk 一次 1 跳，对邻居再调 | 一次请求 2 跳（工具无此参数，属误用） |
| 冲突视角 | 研判/对立题必然走到 `mode=conflicts`，两造都读 | 只讲一边或平均化 |
| 停转纪律 | `on_topic_new=0` 时换动作或声明盲区 | 反复空转加大 limit |
| 写入 | propose_write → 用户确认 → 落盘 + Journal；enrich 用补丁不重抄 | 绕过确认 |
| 动效 | retrieve.query→graph.hit→card.read→write.applied→session.idle 依次呈现 | 事件与工具动作不对应 |

## T1 思考循环核心（5 条 · 15 分钟）

| # | 提示词 | 预期工具序列 | 观察点 |
|---|---|---|---|
| T1-1 定位 | `我想找银行危机预警相关的研究，从哪张卡切入比较好？` | graph_search("银行危机 预警") → read_card（1–2 张，如「用缺口联合阈值预警银行危机」） | 检索波动效；channel=lexical；hub_ratio 合理 |
| T1-2 多跳 | `从「狂热困境恐慌形态学」出发，它沿论证边连着哪些卡？然后挑一个最有意思的邻居再走一跳` | graph_walk（1 跳）→ 挑邻居再 graph_walk（第二跳） | via/direction 标注；graph.hit 沿边扩散；**两次调用而非一次 2 跳** |
| T1-3 冲突 | `「1873年铸币法案作者归因争议」的两造分别是谁？库里有别的 conflict 卡覆盖它吗？` | graph_walk mode=conflicts → 两造 read_card | parties/covering_conflicts 字段；若 uncovered 应见 debt 提示 |
| T1-4 类比 | `「狂热困境恐慌形态学」这个模型，在别的领域有没有结构上相似的机制？` | graph_analogize（model 起点） | channel=analogical；返回 why/score；跨域（不含同域成员） |
| T1-5 停转 | `搜索：量子纠缠与天气系统` | graph_search（n=0 或 on_topic_new=0）→ 模型声明盲区/建议换词 | 空观察合法；**不应编造**、不应反复空转 |

## T2 技能剧本（4 条 · 20 分钟）

| # | 提示词 | 预期 | 观察 |
|---|---|---|---|
| T2-1 talk 深思 | `宏观金融稳定和微观价格稳定到底是什么关系？别罗列卡名，给我一个能立得住的机制解释` | search → walk（含入边）→ read_card(slots=失效边界/模式描述) → 综合 | 精读用 slots 省上下文；归因清楚 |
| T2-2 assess 研判 | `研判：最后贷款人制度到底是稳定器还是道德风险源头？用 3 个透镜，冲突透镜必须把两边都拉出来` | 每透镜 ≥1 次 search/walk；冲突透镜必须 `graph_walk mode=conflicts` + 两造 read_card | 3 次透镜动作可数；冲突透镜不缺席 |
| T2-3 emerge 候选 | `记一下：如果央行只盯通胀会错过资产价格泡沫，这个想法值得沉淀` | graph_search（近义检查）→ walk/conflicts → propose_write（候选，可能 enrich 近义卡）→ 等你确认 | 候选前检查近义/冲突；确认弹窗出现 confirm_request 帧 |
| T2-4 refine | `「价格稳定并非金融稳定充分条件」这张卡，论证还能补一层（资产价格渠道），帮我看看` | read_card → 讨论差异 → propose_write mode:"enrich" 补丁 → 确认 | enrich 补丁不重抄全文；warnings 说明补丁结果 |

## 快速跑测建议

1. **先跑 T0 + T1-1/T1-2/T1-3/T1-4**（约 10 分钟）：覆盖四个核心动词 + 动效，验证思考循环骨架。
2. **再跑 T2-2（assess）与 T2-3（emerge→T3-1）**：验证技能剧本与写入审批闭环（含 enrich）。
3. **T5 三连**：验证失败路径不撒谎、会记债。
4. 每次跑完检查：`node tests/graph-ops.test.mjs`（28 用例）确认后端无回归；图谱动效帧与工具动作一致。
