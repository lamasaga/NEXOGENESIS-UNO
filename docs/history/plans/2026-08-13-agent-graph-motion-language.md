# Agent—知识图谱动效语法与实施清单

> 日期：2026-08-13  
> 状态：已实施  
> 目标：让图谱只随 Agent 的真实知识操作变化，并让检索、命中、关系展开、读卡、判断与写入可以被直观区分。

## 审计结论

  当前后端已经发出 `skill.trigger → retrieve.query → graph.hit → card.read / lens.begin → write.applied → session.idle` 的认知事件，但前端只完整表现了其中一部分。`retrieve.query` 没有空间反馈；关系高亮按线束分组，可能点亮 Agent 没有实际访问的边；边的传播方向没有根据检索种子确定；结束事件会立即清除连线；图数据刷新会重建激活引擎，导致写入动画中断或依赖 SSE 重放恢复；新建与丰富也缺少动作差异。

## 动效语法

| Agent 行为 | 真实事件 | 图谱表现 | 不应表现的内容 |
|---|---|---|---|
| 准备技能 | `skill.trigger` | 状态卡切换，旧激活柔和收束 | 随机点亮知识节点 |
| 发起检索 | `retrieve.query` | 全图细线扫描波 | 在命中前假定具体卡片 |
| 零命中 | `graph.miss` | 扫描波收束，明确显示未找到直接命中 | 伪造扩散路径 |
| 召回种子 | `graph.hit: seed` | 命中节点依次出现细环与暖色光晕 | 同时跳亮全部节点 |
| 关系展开 | `graph.hit: expand/conflict` | 仅沿返回的精确边，从种子端向外传播；线色沿用关系原色 | 按领域线束整组点亮 |
| 阅读卡片 | `card.read` | 单节点聚焦环，显示卡片标题 | 把召回候选冒充已读依据 |
| 透镜判断 | `lens.begin` | 透镜节点和实际关系边以琥珀节奏展开 | 与普通检索使用完全相同的表现 |
| 新建知识 | `write.applied.created` | 新节点向外成形的双环 | 与丰富旧卡使用相同动作 |
| 丰富知识 | `write.applied.enriched` | 旧节点向内收束的更新环 | 暗示创建了新节点 |
| 本轮结束 | `session.idle` | 连线、扫描与节点按各自最短可读时长柔和退出 | 瞬间熄灭 |

## 工程约束

- 事件 `event_id` 必须跨 Publisher 实例唯一，前端按其去重，避免 SSE 重连后重复播放。
- 带会话过滤的 SSE 订阅只接收本会话事件，避免其他对话驱动当前图谱。
- 激活引擎跨图数据刷新保持同一实例；刷新只更新边拓扑，不重置正在播放的写入状态。
- `source_ids` 明确关系扩散的起点；缺失时才回退到关系定义方向。
- `prefers-reduced-motion` 下取消扫描循环与传播前锋，只保留低强度的即时状态差异。
- 激活遮罩只负责建立焦点，不得把整张图压暗到难以辨认。
