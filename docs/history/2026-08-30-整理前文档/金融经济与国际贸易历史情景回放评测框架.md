# 金融、经济与国际贸易历史情景回放评测框架

> 文档状态：现行设计，尚未实现。  
> 上位设计：[思维体分析测评台：行业调研、评测设计与实施规划](思维体分析测评台-行业调研与实施规划.md)  
> 目标：用真实历史数据和当时可获得的信息，评估 DSH 在特定情景下的分析、预测、更新与解释能力，并与统计模型、人类共识和不使用知识图谱的模型基线比较。

## 一、核心判断

  这批评测不应被设计成“给模型一段历史材料，让它解释后来为什么发生”。大模型普遍知道著名历史事件，如果没有严格时间截面，它很容易把事后知识伪装成事前判断。真正有价值的形式是 historical replay，也就是历史时间截面回放：把系统置于某个 `as_of` 日期，只允许使用当日已经发布的数据、报告和知识卡，然后要求它给出概率化判断、风险排序和依据；之后再用真实发展检验。

  历史回放仍不能完全消除模型预训练中的历史记忆。因此，第一批框架必须同时包含“具名历史题、匿名化回放题、顺序更新题和未来前瞻题”。历史题适合比较同一模型在不同检索条件下的相对提升，但不能单独证明模型具有真实预测能力。最终仍需保留一组尚未揭晓结果的 live holdout，随时间自然结算。

  对 DSH 最有价值的不是只预测 GDP 或汇率的一个数字，而是检验它能否：

1. 在当时的信息边界内识别真正重要的变量和结构关系。
2. 区分基准情景、上行风险、下行风险和低概率高影响风险。
3. 给出可校验的概率、方向、幅度区间和时间尺度。
4. 新信息到来后合理更新，而不是坚持原结论或随最新消息剧烈摆动。
5. 用知识图谱形成比裸模型和平面检索更完整、更有边界的分析。

## 二、必须分开的四条评测轨道

### 2.1 事前预测

  在固定日期回答“未来 3、6、12 或 24 个月可能发生什么”。输出必须包含目标变量、概率、区间、时间范围、前提和可能推翻判断的新信号。

  适合评估 GDP、通胀、失业、政策利率、汇率方向、贸易增长、进口依赖、衰退概率和政策转向概率。

### 2.2 顺序信息更新

  同一案例分为多个时间节点。系统先依据 T0 信息作判断，再依次收到 T1 数据发布、T2 政策声明、T3 外部冲击。每一步都要保存预测变化和理由。

  这条轨道最能检验 Agent Loop：Observation 是否改变 Workspace，TM 是否主动寻找反证，OPS 是否在新信息出现后调整检索路径。

### 2.3 截止时点因果诊断

  问题不是预测单个数字，而是在当时判断“哪些机制最可能主导局势”。例如 2007 年中分析美国住房、影子银行和全球失衡之间的关系。评分重点是证据、机制、替代解释和可证伪条件，而不是要求唯一因果答案。

### 2.4 条件情景与反事实

  给定一个当时尚未发生但合理的条件，例如“若油价六个月内上涨 50%”“若主要贸易伙伴加征 20% 关税”，要求系统推演传导路径、受影响对象、二阶效应和监测指标。

  反事实不能仅用真实历史结果评分。应使用结构一致性、方向合理性、证据覆盖和专家 rubric，并在存在相似历史冲击时做外部类比验证。

  四条轨道必须分别报告成绩。一个擅长事后解释的系统，未必擅长事前预测；不能用综合平均分掩盖这种差异。

## 三、时间截面与防泄漏契约

### 3.1 每条信息至少有四个时间字段

```json
{
  "observation_period": "2007-Q2",
  "published_at": "2007-07-27",
  "available_at": "2007-07-27T14:00:00Z",
  "revision_vintage": "2007-07-27"
}
```

- `observation_period`：数据描述的经济时期。
- `published_at`：发布机构公布的日期。
- `available_at`：评测 Agent 可以使用它的最早时点。
- `revision_vintage`：该数值属于哪一次发布或修订版本。

  评测读取权限由 `available_at <= as_of` 决定，不能只看数据所属年份。2007 年 GDP 的 2025 年修订值在 2007 年回放中不可见。

### 3.2 知识卡也必须时间化

  不能直接把当前生产知识图谱用于历史预测，因为现有 Card 很可能已经吸收事后报告、后来研究和最终数据。历史评测应使用独立 fixture，Card 只由截止时点以前的材料编译和消化，并在快照中记录：

- 原始材料发布日期。
- Card 首次可用日期。
- Card revision。
- 来源文件与页码或语义锚点。
- 是否包含后续修订或事后解释。

  这仍然遵守 Markdown 主权，但评测 fixture 与实际知识体隔离，测评台只有只读权限。

### 3.3 同时保存两种真实结果

  宏观数据会修订。每个数值目标建议同时保存：

- `first_release_outcome`：当时首次公布的结果，最接近现实决策者之后看到的反馈。
- `latest_revised_outcome`：当前较完整的最终估计，反映今天对历史的最佳认识。

  短期预测优先对首次发布值评分，同时报告对最终修订值的误差。长期结构判断可更多参考修订值，但必须说明口径。否则系统可能因为预测了一个后来被大幅修订的数字而被错误奖励或惩罚。

### 3.4 控制模型自身的历史记忆

  这是本框架最大的效度风险，不能用提示词“请忘记未来”解决。建议组合使用：

1. 具名案例：保留真实国家、年份与机构，测试知识使用和可解释性。
2. 匿名案例：对国家、机构、日期和事件名称做一致映射，只保留数据结构和当时文本。
3. 扰动案例：在不破坏经济约束的前提下缩放数值、平移年份或替换主体，测试是否依靠事件记忆。
4. 反事实分支：从真实截面生成多个未实际发生但结构合理的政策或冲击条件。
5. 实时前瞻集：保存今天尚未揭晓的问题，未来自动结算。

  若具名案例显著高于匿名案例，应把差异标为“历史记忆增益”，不能归功于知识图谱。只有 DSH 相对同模型基线在具名和匿名案例中都稳定提升，才能说明 TM+OPS 或 GraphOps 真正有效。

## 四、实验组与基线

| 代号 | 配置 | 作用 |
|---|---|---|
| S0 朴素统计 | 不变预测、历史均值、季节朴素或 AR(1) | 判断系统是否胜过最低成本预测 |
| S1 专业共识 | SPF、IMF WEO、OECD Outlook 等当期预测 | 与真实专业预测者比较 |
| M0 裸模型 | 同一 DeepSeek，不提供历史知识图谱 | 控制模型预训练知识 |
| M1 数据包模型 | 提供固定表格和材料包，不允许自主检索 | 测试“给材料”本身的增益 |
| M2 平面检索 | 允许关键词或向量 Top-K，不使用关系扩展 | 与普通 RAG 比较 |
| DSH-S 稳定版 | 当前稳定 TM + OPS + Graph + Loop | 项目当前基线 |
| DSH-C 候选版 | 待测 TM、OPS、Card 标注或 Loop | 判断改动是否晋升 |

  所有模型组使用相同模型版本、表达要求、token 上限和任务时间。S0 与 S1 不需要生成长文，只参与可量化预测指标；M0—DSH-C 同时比较预测和分析报告。

  专业共识是非常重要的基线。费城联储 SPF 从 1968 年起提供历史均值、中位数、个体预测和概率变量；IMF WEO 保存历史预测版本。它们能回答“DSH 是否只是说得更丰富，还是确实比当时专业共识多识别了一些风险”。

## 五、输出契约

  每次历史预测不应只输出散文。建议把机器可评部分固定为以下结构，再允许生成用户可读分析：

```json
{
  "as_of": "2007-06-30",
  "base_case": {
    "description": "未来十二个月增长放缓但避免系统性衰退",
    "probability": 0.55
  },
  "scenarios": [
    {
      "name": "信用收缩扩散",
      "probability": 0.30,
      "horizon": "12m",
      "observable_outcomes": ["住宅投资继续下降", "信用利差扩大"],
      "triggers": ["逾期率上升", "批发融资收缩"],
      "evidence": ["card-id#anchor"],
      "disconfirming_evidence": ["card-id#anchor"]
    }
  ],
  "numeric_forecasts": [
    {
      "target": "real_gdp_growth_yoy",
      "horizon": "12m",
      "point": 1.2,
      "interval_50": [0.2, 2.0],
      "interval_90": [-1.5, 3.0]
    }
  ],
  "confidence": 0.62,
  "next_update_signals": ["card-id#anchor"]
}
```

  场景概率总和应接近 1。最终报告必须明确哪些是数据事实、知识卡主张、模型推断和条件假设。

## 六、评分体系

### 6.1 数值与概率预测

| 指标 | 用途 |
|---|---|
| MAE / RMSE | 点预测误差 |
| 相对 MAE | 与 S0 朴素预测比较，跨变量更容易解释 |
| 方向准确率 | 增长、下降、收紧、放松等方向是否正确 |
| Brier Score | 二元事件概率，如衰退、危机、政策转向 |
| Log Score | 对高置信度错误施加更强惩罚 |
| 区间覆盖率 | 真实值落入 50% 与 90% 区间的频率 |
| 校准曲线 | 声称 70% 的事件是否约七成发生 |
| CRPS | 连续概率分布的整体质量，第二阶段再引入 |

  第一版优先使用相对 MAE、Brier Score 和区间覆盖率。它们已能分辨准确度、概率质量和不确定性是否过窄，不必一开始引入全部统计指标。

### 6.2 情景识别

- 真实发生的重要机制是否出现在事前 Top-3 情景中。
- 对真实路径分配的事前概率是否合理。
- 是否遗漏低概率但高影响、且当时已有迹象的风险。
- 是否把事后才出现的不可知冲击误判为当时应当预见。
- 触发条件与监测指标是否能在后续数据中被观察。

  “2019 年底没有预测到具体的新冠疫情”不应直接视为失败；如果系统识别了供应链集中、全球流动骤停和公共卫生冲击的脆弱性，则可在风险覆盖上得分。必须区分可预见风险和真正的新外生冲击。

### 6.3 分析报告

  沿用思维体测评台的证据可靠性与价值评分，并增加四项经济分析专用 rubric：

- 时间口径：没有混用当时数据和修订数据。
- 传导链：从冲击到价格、数量、资产负债表、政策和国际溢出的路径完整。
- 内生反应：考虑央行、财政、企业、家庭和贸易伙伴会改变行为。
- 尺度匹配：短期市场冲击与长期结构变化没有混为一谈。

### 6.4 顺序更新

  每个新信息节点检查：

- 更新方向是否与新证据一致。
- 概率变化幅度是否与证据强度相称。
- 新 Observation 是否进入 Workspace 并改变下一步。
- 新信息是否降低后续预测误差。
- 是否出现无理由反复横跳或对最初观点的锚定。

  可以报告 `update_gain = 更新前误差 - 更新后误差`。但单次负值不一定说明更新错误，应在一组案例上观察平均增益和校准变化。

### 6.5 知识图谱的独立贡献

  DSH-S 相对 M2 的差异才是知识图谱结构贡献的主要证据。重点记录：

- 沿边扩展找到的有效新证据数量。
- 冲突卡、领域卡和跨域桥接卡是否改变了结论。
- 图关系带来的必要证据覆盖增量。
- 相比平面检索减少了多少无关深读。
- 哪些分析价值提升能够追溯到具体关系路径。

  仅仅调用更多 OPS 或点亮更多图谱节点不算提升。

## 七、首批案例设计

### 7.1 建议规模：24 个案例、约 60 个时间节点

| 轨道 | 案例数 | 时间节点 |
|---|---:|---:|
| 事前预测 | 8 | 8 |
| 顺序更新 | 6 | 24—30 |
| 截止时点诊断 | 6 | 12 |
| 条件情景与反事实 | 4 | 8—12 |

  第一轮不宜直接做上百题。24 个案例已经足以暴露检索、时间泄漏、概率表达、更新和证据组织中的主要问题，也仍能由人逐题审阅。

### 7.2 候选历史情景池

| 截止时点 | 情景 | 适合测试的能力 |
|---|---|---|
| 1973 年中 | 布雷顿森林体系解体后的通胀、美元与能源风险 | 制度变化、商品冲击、国际传导 |
| 1979 年中 | 高通胀环境下货币政策与衰退风险 | 政策反应函数、代价权衡 |
| 1985 年广场协议前 | 美元高估、经常账户与国际协调 | 汇率、贸易失衡、政策博弈 |
| 1992 年 ERM 危机前 | 固定汇率、资本流动与政策可信度 | 约束冲突和脆弱性识别 |
| 1997 年泰铢危机前 | 外债、汇率制度、资本流动和区域传染 | 危机传播与资产负债表分析 |
| 2001 年中国加入 WTO | 贸易结构、产业转移与全球失衡 | 中长期结构情景与双边影响 |
| 2007 年中 | 美国住房、信用扩张和全球金融风险 | 早期预警、反证、尾部风险 |
| 2008 年 9 月 | 金融危机后的政策与贸易坍缩 | 顺序更新、政策缓冲和全球传导 |
| 2010 年春 | 欧债危机、银行主权循环和欧元制度约束 | 多层制度分析 |
| 2015 年中 | 中国增长换挡、汇率调整与大宗商品 | 跨市场传导与情景概率 |
| 2018 年春 | 中美关税升级前的贸易与供应链风险 | 贸易政策、替代与转移效应 |
| 2021 年中 | 通胀暂时性争论和政策路径 | 冲突证据、更新和校准 |

  第一批应从其中挑 6—8 个，不要让危机案例占满数据集。还应加入“最终没有发生危机”的正常时期，否则系统只要持续悲观就能取得虚假好成绩。建议危机、软着陆、结构转型和政策成功各占一定比例。

### 7.3 负例与对抗案例

- 标题相似但国家、时期或制度背景不同的 Card。
- 后来被大幅修订的宏观数据。
- 当时流行但最终失败的主流解释。
- 同一冲击在固定汇率与浮动汇率国家的不同结果。
- 关键结果由不可预见外生冲击造成的案例。
- 事后相关、事前不可用的研究论文和历史总结。

  负例不是为了“骗模型”，而是检验它是否遵守适用范围、时间边界和证据权重。

## 八、可借鉴的项目与方法

| 项目 | 可借鉴内容 | 不应直接照搬之处 |
|---|---|---|
| [ForecastBench](https://forecastbench.org/) | 动态未决问题、概率预测、Brier 评分、人类基线、持续结算 | 题目多为独立事件，没有 DSH 的证据图和长篇分析 |
| [FRED-MD / FRED-QD](https://www.stlouisfed.org/research/economists/mccracken/fred-databases) | 标准化宏观变量、历史 vintage、实时更新、统计预测基线 | 主要覆盖美国宏观数值，不评估叙事与图推理 |
| [Survey of Professional Forecasters](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/survey-of-professional-forecasters) | 1968 年以来的人类共识、个体预测、概率和分歧 | 主要是美国，且分析理由不可完整获得 |
| [FinanceBench](https://arxiv.org/abs/2311.11944) | 金融文档问答、答案与证据页对应 | 偏 SEC 文件检索，不是宏观情景推演 |
| [FinQA](https://finqasite.github.io/) | 表格与文本联合数值推理、显式计算程序 | 以封闭答案为主，不能衡量开放式研判 |
| [DeepResearch Bench](https://deepresearch-bench.github.io/) | 完整性、洞见、指令遵循、可读性和引用准确率 | 使用开放网络研究，不包含 point-in-time 宏观数据契约 |
| [JST Macrohistory Database](https://www.macrohistory.net/database/) | 1870 年以来的信用、住房、资产回报和金融危机长期比较 | 年度频率较低，且不能替代当时可获得的数据版本 |

  DSH 的框架应当把 ForecastBench 的概率预测、FRED 的实时 vintage、SPF 的人类共识、FinanceBench 的证据锚定和 DeepResearch Bench 的分析 rubric 组合起来，而不是寻找一个现成项目直接移植。

## 九、数据源与适用范围

### 9.1 第一优先级：可支持真实时间截面的数据

| 数据源 | 适合内容 | 关键说明 |
|---|---|---|
| [ALFRED / FRED Real-Time](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html) | 美国 GDP、通胀、就业、货币、金融条件等 | 可按历史 real-time period 或 vintage 读取当时已知值 |
| [FRED-MD / FRED-QD vintages](https://www.stlouisfed.org/research/economists/mccracken/fred-databases) | 月度、季度大规模宏观预测 | 已整理历史版本，适合统计基线与回放 |
| [Philadelphia Fed SPF](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/mean-forecasts) | 美国专业预测共识与概率 | 可作为 S1 人类基线 |
| [IMF WEO 历史预测](https://data.imf.org/Datasets/WEO) | 多国增长、通胀、财政、经常账户预测 | 使用对应发布期 vintage，不得用最新数据库回填 |
| OECD Economic Outlook | OECD 国家的当期预测和结构指标 | 通过 Data Explorer/SDMX 获取，需保存发布版本 |

### 9.2 第二优先级：国际贸易与跨国结构

| 数据源 | 覆盖与用途 | 注意事项 |
|---|---|---|

### 9.4 原始报告和当期叙事材料

  数值数据无法替代当时的决策语境。每个案例还应收集截止时点以前发布的央行会议材料、IMF Article IV/WEO 章节、WTO 报告、政府预算、企业年报和研究机构报告。美国公司层案例可通过 [SEC EDGAR API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 获取带提交日期的 10-K、10-Q 与 XBRL 数据。

  这些文档应先进入独立评测 Inbox，通过和生产环境相同的 compile/digest 规则形成快照 Card。这样评测的不只是答案模型，也包括 DSH 的知识摄入质量。

## 十、数据集构建流程

1. 选定事件与 `as_of` 日期，先写评测问题和可观察目标。
2. 获取该日期对应的数据 vintage、专业预测和当期原始文档。
3. 建立只含当时材料的独立 Markdown 知识体 fixture。
4. 由领域人员标出必要证据、关键反证、当时不可知因素和可接受情景。
5. 保存首次发布结果、最终修订结果和真实事件时间线。
6. 生成具名、匿名、扰动和必要的反事实版本。
7. 运行 S0、S1、M0、M1、M2、DSH-S；保存 Episode 与 Workspace。
8. 先校准评分器，再把案例分为 development 与 holdout。

  数据集版本必须记录原始下载地址、抓取时间、许可、转换脚本和哈希。任何后来修订都生成新版本，不覆盖旧 fixture。

## 十一、统计比较与结果解释

  每个 DSH 配置至少重复运行三次。报告逐案例 paired delta，并对案例进行 bootstrap，给出提升区间。数据量尚小时，不应过度强调显著性检验；更重要的是列出严重回归、不同情景类型的胜负分布和结论稳定性。

  建议最终报告保留以下核心数字：

- 相对 S0 的数值预测误差改善。
- 相对 S1 的概率预测和情景覆盖差异。
- DSH-S 相对 M0/M2 的可靠性、价值和知识图谱增量。
- 具名与匿名案例的性能差，作为历史记忆风险指标。
- 顺序更新平均增益。
- 严重无依据断言和未来信息泄漏次数。
- 每案例 token、时间、OPS 数和有效读卡率。

  历史真实结果只回答“后来发生了什么”，不能证明某一种因果解释为真。因此预测结果可以自动评分，因果报告仍需证据 rubric、替代解释和专家复核。

## 十二、建议的实施顺序

### 第一阶段：8 个最小回放案例

  先选择数据条件最好的 1997、2007、2010、2015、2018、2021 等时期，建立 8 个 fixture。实现 `as_of` 权限、ALFRED/FRED vintage、SPF/WEO 基线、结构化预测输出、Brier/相对 MAE 和未来信息检查。

  验收重点不是高分，而是同一案例能够可靠重放，系统不能读到截止日后的 Card 或数据。

### 第二阶段：24 个案例与顺序更新

  扩展到四条轨道，引入 BACI/Comtrade/WTO 数据和匿名案例。实现多个时间节点、Workspace 更新评分、分析报告 A/B 和专家校准。

### 第三阶段：实时前瞻集

  每月建立 5—10 个尚未结算的问题，冻结输入和预测。到期后自动取得首次发布结果并评分。实时集是检验历史记忆污染的最终手段，但在结果揭晓前只报告运行健康度，不报告准确率。

## 十三、当前不建议做的事

- 不直接用当前完整知识图谱回测历史。
- 不把最新修订数据伪装成当时已知数据。
- 不只选择著名危机和容易事后解释的案例。
- 不用资产投资收益作为第一批唯一目标，避免交易成本、可交易时点和幸存者偏差扩大范围。
- 不把当前模型在著名历史事件上的高分宣称为真实预测能力。
- 不把 GDELT 等自动事件数据当作无误事实源。
- 不让一个综合 Judge 分数覆盖数值误差、证据错误或泄漏问题。

## 十四、最终建议

  第一批评测建议聚焦“宏观—金融—贸易冲击的时间截面分析”，而不是直接做选股或交易 Agent。以 1997—2021 年的 8 个高质量案例起步，先打通 ALFRED/FRED、SPF/WEO 和 BACI/Comtrade 三条数据链，再加入匿名化和顺序更新。

  这批评测真正要回答的不是“DSH 能不能猜中历史”，而是三个更可靠的问题：在相同模型下，知识图谱是否提高了必要证据覆盖和反证能力；TM+OPS 是否形成了更好的情景结构与更新行为；这些提升是否在匿名案例和未来前瞻案例中仍然存在。
