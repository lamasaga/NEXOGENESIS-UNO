# 运行指南

## 启动

```cmd
cd /d D:\UESR\Desktop\NEXOGENESIS-DSH
start-nexogenesis.cmd
```

  默认使用 `nexogenesis` profile 和 3083 端口。也可以直接指定其他测试端口：

```powershell
& 'D:\KimiData\daimon-share\daimon\npm-global\dsh.cmd' --profile nexogenesis --port 3099
```

  3080 保留给官方 DSH 界面。修改 `AGENTS.md`、preset 或工具注册后，应重启 DSH 再测试。

## 第一次配置

  打开 `http://127.0.0.1:3083`，在设置中填写 DeepSeek API Key。凭据保存在 DSH 用户目录，不进入项目 Git。

  若希望 Web 编译自动复核 PDF 关键图片，在“设置 → 模型连接 → 图像理解模型（编译专用）”中另行填写支持 OpenAI-compatible `image_url` 输入的 Base URL、模型名称和密钥。该模型只处理图片候选，不替换 DeepSeek 主对话模型；留空时正文编译仍可运行，图片候选会明确延后。

## 常用测试

  工具和写入测试：

```powershell
$tests = Get-ChildItem tests -Filter '*.test.mjs' | Sort-Object Name
foreach ($test in $tests) {
  node $test.FullName
  if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
```

  前端测试和构建：


```powershell
Invoke-RestMethod http://127.0.0.1:3083/api/health
```

## 手工验收

### 对话

1. 新建普通对话。
2. 提问一个需要知识库的内容。
3. 确认模型调用检索工具，并能打开来源卡片。
4. 在后台任务运行时继续普通对话，确认两者互不阻塞。

### 编译

1. 把一份短 Markdown 或 EPUB 放入 `00-Inbox/`。
2. 点击左侧“编译”，在弹窗中选择本次材料并确认；也可以在编译固定线程中直接输入 `/compile`。
3. 确认页面只把所选材料交给任务，并由模型先建立材料索引、再按需读取和写出可读 Buffer。
4. 对 EPUB，确认索引出现章节与 `EPUB spine` 来源位置，而不是压缩乱码；再确认模型只按需读取有限正文片段。
5. 对损坏或加密 EPUB，确认系统报告不可解析，不生成 Buffer。

### 消化

1. 选择一份 Buffer 并输入 `/digest`。
2. 确认模型先检索已有卡，而不是直接新建。
3. 拒绝一次写入，确认结果回到原会话，模型能继续或有理由停止。

### 建构

1. 输入 `/construct` 并给出一个小范围领域。
2. 确认模型调用多个只读或模拟工具，而不是一次发送整库正文。
3. 若提出修改，确认一次只处理一个层面，拒绝后不会直接结束整个任务。

## 常见问题

### 端口被占用

```powershell
Get-NetTCPConnection -LocalPort 3083 -State Listen | Select-Object OwningProcess
```

  先确认进程确实是旧 DSH，再正常停止该进程；不要批量结束不明进程。

### 修改后没有生效

  先确认修改的是本仓源文件，再重启 `nexogenesis` profile。用户级和项目级 `AGENTS.md` 都在新会话启动时重新加载。

### 编译读到乱码

  先看文件格式。当前只可靠支持纯文本和 Markdown；EPUB、PDF、Office 文件不能通过改提示词解决，需要对应解析代码。
