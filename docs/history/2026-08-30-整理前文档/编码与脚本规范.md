# 编码与脚本规范

  本仓主要在 Windows 上开发，只保留已经反复造成问题的约定。

## 文件编码

- JavaScript、TypeScript、Markdown、YAML 和 JSON 使用 UTF-8。
- `.cmd`、`.bat` 保持 ASCII，避免系统代码页破坏命令。
- 必须包含中文的 PowerShell 5.1 脚本使用 UTF-8 BOM；优先使用 PowerShell 7。
- 不为解决单个项目问题修改全局系统代码页。

## 脚本

- 启动项目使用 `start-nexogenesis.cmd` 或明确的 `dsh.cmd` 路径。
- `.cmd` 调用另一个 `.cmd` 时使用 `call`。
- 新脚本只解决重复出现的开发操作，不为一次性命令建立脚本框架。
- 脚本不得自动结束不明进程、删除宽泛目录或修改系统级配置。

## JavaScript

- 使用 ESM，与现有包保持一致。
- 工具参数以注册的 JSON Schema 为准；描述、示例和实际校验必须一致。
- 优先修改现有模块；只有职责已经重复或文件难以维护时才拆分。
- 行为变化应补最接近问题的测试，不以新增类或目录作为完成证明。

## 文档

- 只描述当前代码中存在的路径、命令和能力。
- 首次出现内部名称时用白话说明其作用。
- 历史方案放入 `docs/history/`，不继续修改成现行说明。
- 中文自然语言段落遵守用户级首行两个半角空格规则。
