# 真实回归案例

  本目录保存生产对话中已经发生、能够由真实会话轨迹和 CognitiveRun 记录复核的思维体案例。它与冻结历史情景评测集分工不同：历史情景案例评估固定时点下的判断质量，本目录用于防止真实 Skill、TM、OPS、运行状态、完成门和界面呈现退化。

## 收录条件

- 输入来自真实用户任务，不是为了测试临时编造的提示词。
- 至少保留用户输入、可观察工具轨迹、运行状态、最终结果和人工判定。
- 明确区分回答质量、证据质量、图结构利用、任务治理和界面呈现。
- 不保存或推断模型隐藏思维链，只检查真实 Observation、Workspace、Episode、回执和输出。
- 案例先作为人工回归基线；只有建立冻结知识 fixture 和执行适配器后，才能标记为可自动运行。

## 使用纪律

  回归不以工具调用数、回答篇幅、动画节点数或固定跳数作为成功标准。只有必要的证据义务被真实满足、观察改变了后续行动、任务状态正确闭合且最终输出忠实反映证据边界时，案例才算通过。

  修复通过本目录案例后，仍须运行现有确定性测试和历史情景评测；单个真实案例不能独自证明 TM 或 OPS 已获得普遍收益。
