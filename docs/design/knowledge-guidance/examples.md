# 卡片正文示范

以下材料均为虚构教学样例，不得作为真实知识写入库中。示例展示细节密度与作者归属，不要求复制所有小标题。

## 机制、观点：参与成本如何影响反馈偏差

摘要：样例作者认为，反馈渠道要求的时间和表达能力会改变参与者构成，收到的意见因而不等于所有受影响者的意见。

### 作者的解释
作者从参与门槛解释反馈偏差：提交意见需要填写长表单时，有时间、熟悉规则的人更可能完成；管理者若据此推断群体偏好，会放大这部分人的诉求。这里需要同时区分“谁愿意说”和“谁能够说”，不能把沉默自动理解为赞同。

### 传导过程
复杂表单增加时间与表达成本，参与者因此发生选择；选择后的意见分布再进入决策。偏差产生在意见进入系统之前，单纯增加收到的意见数量未必消除它。作者提出减少表单负担，并比较不同渠道的参与者构成。

### 证据与分歧
样例材料以社区征询为解释性案例，没有给出对照试验。另一位受访者认为，利益受损程度也影响参与意愿；该意见是可能共同起作用的解释，不能无依据合并成作者原模型。

边界：限于材料讨论的自愿反馈渠道；没有证据估计偏差大小，也不保证简化表单必然提高代表性。
来源：实际生成时填写真实原文单元和定位，不能使用此样例路径。

## 案例、现象：社区征询的渠道差异

摘要：样例社区同时开放纸质表单和在线留言，出现参与者构成差异；它帮助说明渠道条件如何影响可见意见。

### 情境与经过
征询针对停车安排。纸质表单在白天现场领取，在线留言全天开放。样例作者观察到两条渠道的发言者构成不同，但未公布完整人数或抽样方法。因此能够沉淀的是“案例中出现渠道差异”的描述，而不是群体比例或因果效应。

### 可共享的观察
案例可被参与成本、数字渠道可达性等不同解释引用。引用时分别说明解释用途，避免把案例重写成每个模型的独占证据。

边界：单一社区的叙述性案例；材料没有识别时间安排、渠道熟悉程度与利益强度的独立作用。
来源：使用真实材料中的主体、时间和定位；原文没有的信息不补造。

## 方法：比较反馈渠道的参与者构成

摘要：样例材料提出比较不同反馈渠道的参与条件与实际参与者，判断意见收集是否遗漏特定人群。

正文应保留输入（渠道规则、参与记录）、具体操作（对比开放时段、所需时间、身份限制及群体覆盖）、输出（遗漏线索）和后续判断。缺少人口基线时只能提出遗漏风险，不能输出代表性分数。若来源只提倡“多听意见”，不可编造上述步骤作为其方法。

## 其他类型的实质要求

- 概念：说明对象、定义、与易混概念的区别。例如“沉默”是一种未表达状态，不能在没有材料支持时等同“认可”。
- 模型：说明组成部分、它们的联系和被解释对象。流程图标题清单不能代替联系的解释。
- 实体：写清主体身份、时间范围、与研究问题相关的制度或行为。名称、宣传语和链接列表不构成完整实体卡。

## 不合格写法

“核心观点：参与很重要。启示：要重视参与。边界：原文未提及。”缺少对象、传导与证据范围；即使有小标题也不合格。标题、摘要、正文三次重复同一句话同样不合格。
