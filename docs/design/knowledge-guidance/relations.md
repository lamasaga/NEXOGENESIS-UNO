# 关系类型：定义、方向、边界与示例

> 配合[使用说明](README.md)阅读。以下为假设材料下的教学示例，不是真实研究结论；实际关系必须根据当前卡片及其来源判断。本文与当前工具契约共同使用。

## 如何理解一条关系

关系回答：“为了理解当前内容，还值得读取另一张卡片的什么？”它既不是相似度分数，也不自动构成证明。

保存联系时，指明两端、类型和简短的关联说明。说明应指出实际比较维度、补充内容或案例用途，例如“乙卡补充甲卡没有展开的参与条件”；避免“二者有深刻联系”这样的空话。依据可以定位到卡片已有的来源段落，不要求在关系里重新复制长篇材料。

模型可以依据两端卡片的定义、立场、过程与用途整理导航联系，不要求两篇原文互相引用。link.basis=source 表示来源已表达的联系；basis=navigation 表示模型整理的阅读入口。导航说明必须给出具体比较维度与边界，不冒充作者原有论证，不把因果解释或迁移假设写成事实。例证、质疑与应用尤其要保留作者归属、条件及实际使用情况。

方向只说明从哪类内容走向哪类内容。索引应能反向查找，同一条方向关系不再写一条重复反向边。对称关系保存一次即可。任何关系都不自动传递，不自动继承结论，不扩展成隐藏的多跳论证。

## 1．细分

**定义。** 从较一般的概念或类别进入其中一种更具体的类型。含义接近“下位对象是上位对象的一种”，但作为阅读导航使用，不执行数学集合推导。

**方向。** 上位 → 下位。上位卡可以找到具体分支，下位卡可以反查一般背景。

**使用依据。** 材料的定义、分类或卡片保存的明确内容能够说明类别关系。不要仅凭标题相似判断，也不为了让可视化整齐而建立层级。

**正例。** 假设材料明确把结构性失业列为失业的一种类型，可保存：

> 失业 → 结构性失业｜细分｜后者是材料区分的一种失业类型，强调岗位需求与劳动供给之间的结构不匹配。

**反例。** “政治体制 → 议会”不能仅因议会是其组成部分就标细分；议会不是一种政治体制。“集体行动 → 某次罢工”是类别与具体案例的联系，可使用例证的反向查询，不是概念细分。“社会学领域 → 社会资本”属于领域组织。

**检索价值。** 一般问题可向下展开差异；具体问题可向上取得定义和范围。下位卡不自动继承上位卡的全部判断。

## 2．补充

**定义。** 一张卡为另一张卡补回理解所需的条件、过程、维度或细节。不是一般主题相同，也不等于支持结论。

**方向。** 补充内容 → 被补充内容。

**使用依据。** 能具体指出被补充卡讨论什么，以及另一卡填补了哪部分。两卡若只是重复，应该考虑合并或保留版本差异，不以补充边代替去重判断。

**正例。** 假设甲卡整理协商机制，未展开代表如何获得授权；乙卡根据材料专门整理这一协商中的代表授权条件：

> 代表授权条件 → 协商机制｜补充｜补充协商代表如何获得和维持授权这一前提。

**反例。** 两卡都讨论协商，但一张描述会议场地、另一张描述工资结果，尚不能仅凭同题建立补充关系。“乙的结论与甲一致”也不足以说明补充了什么。

**检索价值。** 避免模型只读抽象结论，遗漏前提或必要细节。

## 3．对照

**定义。** 两张卡在明确维度上存在值得比较的差异，可以是主张、条件、操作方式、时间阶段或结果的差异。差异不必构成逻辑冲突。

**方向。** 对称。说明应指出比较维度，并保留不适合直接比较的条件差异。

**使用依据。** 两端内容足以支持差异描述，不要求作者互相反驳；不额外推断差异导致了什么结果。

**正例。** 假设两份材料分别描述协商代表由选举产生和由抽签产生：

> 选举产生协商代表 ↔ 抽签产生协商代表｜对照｜两者采用不同的代表产生方式；材料中的参与范围也不同，不能直接据此比较成效。

**反例。** “都与政治有关”不构成对照。两者不同也不意味着其中一个反驳另一个，更不能仅凭结果差异宣称某制度更优。

**检索价值。** 获取不同处理方式、替代观点和比较维度。

## 4．质疑

**定义。** 一张卡保存了对另一项主张、解释或适用范围的反对意见、限制条件，或材料明确指出的不吻合案例。表示有必要审视，不表示已经推翻。

**方向。** 质疑内容 → 被质疑内容。

**使用依据。** 材料明确提出质疑，或现有内容已经直接呈现针对同一命题、相同相关条件的不一致。仅“结论看起来不同”时先用对照；若需要额外假设才能构成反例，不在编译中建立确定质疑关系。

**正例。** 假设作者乙明确批评“公开信息必然增加信任”，并用某次公开后信任未增加的调查讨论该命题的限制：

> 信息公开未增加信任的调查 → 信息公开必然增加信任｜质疑｜作者乙用该调查质疑“必然增加”的表述；调查条件与原主张的适用范围见正文。

**反例。** 一份研究讨论危机期间的信任，另一份讨论平常时期，结果不同并不自动构成反例。质疑作者的动机或身份，也不能代替对其观点内容的质疑。

**检索价值。** 主动找回反对意见、边界与反例，减少上下文只有同向材料的情况。

## 5．类比

**定义。** 不同对象或情境具有可比较的结构、角色或过程；可以是来源已表达的类比，也可以是模型根据两端已有内容整理的阅读导航。价值在提供观察角度，不在宣称两个对象完全等同。

**方向。** 对称。说明保留相似之处和关键不相似之处；正文已有详细说明时，关系只需简短指向。

**使用依据。** 来源已表达的类比使用 basis=source。模型依据两端已有内容整理跨材料类比时使用 basis=navigation，说明相似维度和关键不同，不声称该类比已经成立或原作者作过比较。不能只凭共同词语连线，也不能往卡片正文新增来源没有表达的理论。

**正例。** 假设原文明确比较合作社与社区组织的集体议事，指出两者都面对参与成本，但成员资格与利益结构不同：

> 合作社集体议事 ↔ 社区集体议事｜类比｜原文借共同的参与成本问题进行比较，同时指出成员资格和利益结构不同。

**反例。** “国家像一个人，所以国家也一定有相同心理”不能成为类比依据。只共享“竞争”“网络”等词语，也不足以建立类比边。

**检索价值。** 召回来源中的跨域视角，以及经过明确标记的跨材料阅读入口。思考阶段仍须回到正文判断，导航关系不提供证明力。

## 6．例证

**定义。** 一个具体案例被材料用于阐释某个概念、观点、现象、机制或模型。强调作者如何使用这个例子，不自动赋予证明力。

**方向。** 案例 → 被阐释内容。检索观点时可以反查案例。

**使用依据。** 原文明确给出了案例的论证或说明用途；若整理时根据明确的类别定义归入案例，应说明仅作实例导航，不声称原作者进行了因果论证。

**正例。** 假设原文借甲港协商过程解释信息可核对性的重要性：

> 甲港协商过程 → 信息可核对性｜例证｜作者以该事件阐释参与者核对信息的过程；材料没有据此证明所有协商都有相同结果。

**反例。** 任意成功案例不能作为某个理论有效的证据。如果案例主要被作者用于说明理论不成立，应优先使用质疑；不要同时写一句空泛的“也是一个例子”重复连边。

**检索价值。** 补充具体人物、行动、过程与结果，让回答能够解释观点怎样落到真实材料上。

## 7．应用

**定义。** 方法或模型在某个问题、情境或案例中的使用方式，包括来源明确说明的适用场景。可以是实际使用记录，也可以是作者提出的使用建议，两者必须区别。

**方向。** 方法或模型 → 使用情境或应用案例。

**使用依据。** 材料说明如何使用或明确提出可用于何处。模型自行认为“这个方法也能用于别的问题”属于新的应用建议，不作为编译所得的确定关系。

**正例。** 假设某研究说明如何用过程追踪分析甲港协商变化：

> 过程追踪方法 → 甲港协商变化研究｜应用｜研究在该案例中使用过程追踪，操作与证据要求见案例正文。

若作者只是建议用于某问题，说明应写“作者建议用于……，材料未给出实际使用记录”，不能写成已经验证的应用。

**反例。** 一个案例恰好符合某模型的表面描述，不等于参与者或研究者实际使用了该模型。案例被用来阐释模型时可标例证；方法被用于研究案例时才构成应用。实际使用也不自动等于有效。

**检索价值。** 从方法找到使用条件和实际操作，也能从问题情境反查可参考的方法。

## 容易混淆时如何选择

| 容易混淆的情况 | 判断方法 |
|---|---|
| 领域归属 / 细分 | 前者是从哪片知识范围进入；后者要求下位对象是上位概念的一种 |
| 组成部分 / 细分 | “有这个组成部分”不是“它的一种”；暂时在正文保留组成说明，不强造细分边 |
| 对照 / 质疑 | 先看有没有针对同一主张的异议或直接不一致；只是不同则对照 |
| 补充 / 例证 | 前者填补条件或细节；后者强调具体案例对某内容的说明用途 |
| 例证 / 应用 | 作者拿案例解释模型是例证；研究者或行动者使用模型处理案例是应用 |
| 对照 / 类比 | 对照突出差异；类比突出可比较的结构，区分来源联系与整理导航，仍保留差异 |
| 同领域 / 关系 | 同领域、共同标签或词面相似交给索引，不额外创建“相关”关系 |

同一对卡片可以有多种联系，但必须分别提供不同的阅读价值。不为形式完整重复标记，也不为可视化的连通率制造关系。如果尚没有值得保存的联系，可以不连线。

## 一条完整关系的说明示范

以下为便于阅读的文档表达，不是调用工具的参数格式：

> 起点：甲港协商过程<br>
> 关系：例证<br>
> 终点：信息可核对性<br>
> 关联说明：作者借甲港案例说明参与者核对信息的过程；其论证用途限于该材料所述条件。<br>
> 依据位置：案例卡中对应来源段落，可继续回查 Buffer 的章节定位。

必要信息是端点、关系语义与具体关联说明。compile_edit 的 link 使用 `{target,type,note,basis}`（basis 为 source 或 navigation；旧关系省略时保持来源语义）；起点由 id 指定，修改使用当前 revision。来源定位可以复用卡片已有信息。说明不足或依据存疑时记录校对事项；检查用于修订成果，不要求每次写入都重新进行一轮长篇关系论证。


## 领域之间的导航联系

以下关系只用于领域索引，不能填入知识卡片的 link。它们不自动扩展为下属卡片之间的边。

| 参数 | 含义与例子 | 不应使用的情况 |
|---|---|---|
| adjacent 邻接 | 两个领域存在具体交界问题；如劳动研究与组织研究共同涉及劳动控制，说明交界问题后便于切换阅读。 | 仅同属某个学科或大类不足以建立关系。 |
| contrast 对照 | 指出两个领域理解同一问题的视角差异；如政治经济学与行为研究分别关注制度分配和个体选择。 | 不宣称哪一领域自动否定另一领域。 |
| bridge 跨域桥接 | 明确一条跨领域的阅读入口；如从技术治理的算法决策问题进入行政程序中的申诉机制。 | 无来源支持的新理论迁移不写成已有结论。 |

parents 仅记录领域的上层导航，不是卡片类型。representative_card_ids 记录代表卡（旧 card_ids 只读兼容）；卡片自身 domains 可以多归属。领域关系保存 target/type/note/use_when/limits/basis，basis 固定为 navigation，可附 anchor_card_ids。图上领域节点只与领域节点连线，成员关系不伪装成论证。完整说明、示例、Gateway 接口和能力边界见[领域说明与领域关系](domains.md)。

## 跨材料导航正例

两份材料分别讨论平台的规模扩张与组织的授权边界，原作者没有互相引用。若两卡确有这些内容，可保存 `contrast`、`basis: navigation`，说明“比较扩大参与范围与保留决策边界的不同安排；对象与制度环境不同，不推断效果相同”。原作者没有作过比较，不构成删除此导航的理由。若两端内容没有这一比较维度，则应修正或移除。
