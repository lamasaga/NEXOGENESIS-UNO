# UNO 会话控制统一

> 2026-09-13。对齐本地 DSH 当前源码的会话控制设计；本次修改 UNO，DSH 只作参照。原生集成验证使用临时知识库和模拟模型，不代表真实模型的语义质量或正式服务已更新。

聊天、思考和建构现在以主会话承载交互。建构仍使用 UNO 的草稿、独立审核、HarnessGateway 和版本收据；内部作者、审核会话属于同一工作，不再各自决定主会话的停止、删除和显示状态。

## 用户操作

| 操作 | 当前行为 |
|---|---|
| 新对话 / 思考 | 使用同一只读交流流程，每轮判断是否需要检索；普通提问不取得建构写入授权。 |
| 切换对话、关闭页面 | 解除当前浏览器订阅，后台执行继续；返回时读取已保存历史。 |
| 刷新页面 | 按知识库恢复本标签页选中的主会话及编译面板，只查询原任务，不新建或恢复执行。 |
| 断网与重连 | 标明显示的是上次确认状态，暂时禁用执行控制；状态轮询持续重试，事件连接恢复后重新读取历史、任务、实例与图谱。 |
| 开始回执丢失 | 开始前保存请求标识和原要求；重试使用同一标识，后台只返回已创建任务。相同标识更换范围会被拒绝。 |
| 后台进程中断 | 丢失执行句柄的任务显示中断暂停，保留批次、预算、草稿和收据；明确继续后才调用模型。 |
| 暂停执行 | 指向实际作者或审核会话；等待 `turn/end`，或核验原生会话确实空闲。取消请求受理不等于已经退出。 |
| 讨论结果 | 留在主会话只读交流，提供原目标、阶段、进度和预算作为背景。待确认批次保留。 |
| 继续工作 | 保留原范围、批次、审核角色、已完成结果、累计预算和补充要求；不借恢复重置预算。人工待确认批次先从工作详情处理。 |
| 结束这项工作 | 保留成果、草稿及未完成记录，关闭原任务恢复入口；已完成任务保持完成状态。之后仍可只读交流。 |
| 删除对话 | 正在执行、尚未结束的任务或未处理的待答事项会阻止删除；结束后只隐藏会话元数据。 |
| 执行中补充要求 | 接收后保存到任务，后续步骤读取；重复请求标识不会重复入账。全部补充累计最多 12,000 字符，超限明确拒绝。 |

默认单批建构完成后，如果还有下一批，只显示暂停和剩余范围；不会把整个任务标成完成。读过本批而没有必要修改知识，也可如实结束该批。

工作状态统一经 `/api/work` 投影，作者及审核活动通知主会话，刷新后能读到内部执行结果。调度提示仍在原生日志中，聊天记录只呈现结果和用户讨论。快速回答保存时去除不存在的可选字段，以满足原生日志的严格 JSON 约束。

前端不再用仅存于当前页面的发送队列接收运行中补充。迟到的流事件、创建回执及面板操作不能覆盖用户已经切换的会话；未提交草稿仍属于浏览器当前会话，不承诺跨刷新保存。窄屏通过会话列表开关进入不同工作，对话、控制和输入使用完整宽度。

恢复定位使用按知识库划分的 `sessionStorage`，因此保障本标签页刷新；关闭标签页后可从侧栏打开原任务，不承诺恢复标签页视图。开始请求使用 UUID 作为任务 ID，将原输入摘要一同保存在任务文件中，免除第二套请求索引。重复开始请求只读回当前状态，即使任务已经暂停、结束或完成，也不触发执行。缺少请求标识的旧 API 调用保留兼容行为，不具备这项重试保证。

事件流用于及时通知，持久化任务、原生日志和 Gateway 收据才是恢复依据；重连不以补齐每一个瞬时事件作为完成条件。首次读取面板失败、运行中轮询失败都会重试，完成任务仍能同步其他页面的变化。完成后的批次编号限制在实际批次数内，并隐藏无效的结束按钮；后台中断显示实际原因，不描述为已安全完成当前步骤。

## 实现对应

- DSH 参照：`conversation-control.js`、`work.js`、`resume-inbox.js`、`ChatComposer.tsx` 及对话事件归属保护。
- UNO 适配：`uno-jobs.js` 负责工作与主会话映射；`uno-workflow-v3.js` 负责作者/审核交接和实际退出；`work.js` 对外提供统一状态和操作；`chat.js` 将暂停后的输入路由为只读讨论。
- 保留 UNO 的工具、知识结构和独立审核；本次没有把 DSH 的卡片类型或旧编译控制器搬入 UNO。历史任务仍沿其保存的版本处理。

## 验证与边界

后端回归 306 项通过；前端 28 个文件、175 项通过；TypeScript 与生产构建通过。构建仍有约 578 kB 主 JS 的体积提示。

在隔离 DSH 原生宿主和 Edge 浏览器中，以 7 张合成卡片验证两个建构批次，覆盖普通聊天切换后后台完成、主会话接收独立审核历史、只读讨论、补充要求持久化、刷新恢复、按原预算继续、思考入口、主动暂停、结束及迟到回执。桌面 1440×960、移动端 390×844 已检查截图及按钮/输入的实际可见范围。Browser 插件不可用，因此采用本机 Playwright。

仍保留同一知识库同时只执行一项编译或建构的限制；普通聊天可在其他会话继续。取消后原生执行如果始终不退出，仍保持等待，不能伪造成功。长期崩溃恢复、所有供应商的取消行为、真实模型理解与建构收益不在本轮合成验证的证明范围内。

刷新专项在隔离原生宿主与 Edge 中覆盖建构执行中刷新、编译执行中刷新、断网时后台继续至审核发布、首次读取失败后重试、重连同步完成与收据、已受理开始回执丢失后仅 GET 接回原任务，以及实际停止/重启宿主后暂停且不自动调用模型。合成编译通过 Gateway 发布一张测试卡；没有读取真实知识或调用付费模型。此次进程重启发生在建构步骤等待模型时，不代表已验证所有写入瞬间的断电恢复。

正式 UNO 服务未在本轮重启；运行中的旧进程不会加载源码变化。新前端要求 `/api/work.controls_version = 1` 且 `start_request_version = 1`，旧后台不会静默执行不匹配的聊天或开始协议。新后台健康标记为 `work_lifecycle_version = 3`、`conversation_controls_version = 1`、`uno_conversation_lifecycle = 1`、`uno_task_start_requests = 1`。本轮只读核对 3093 仍为 `work_lifecycle_version = 2`，尚未加载上述新增标记。

回退时同步回退本次程序和前端构建，任务与收据保留；不删除或改写真实知识库。本次未修改 DSH、共享配置或真实知识材料。
