# UNO Agent 基础能力改进

核对日期：2026-09-13。本文记录当时的旧草稿/Buffer Agent 能力，仅供追溯。现行新建编译使用 `unit-cards-v3`，知识卡分类只有单一 `type` 与多个既有 `domains`；新卡不写 `tags/topics`。当前契约见 [单元编译实施](UNO-单元编译实施.md)。

## 依据与取舍

最近两轮编译已经暴露了工具回执不合法、全文覆盖、关系参数静默丢失、动态系统提示破坏前缀、旧批待办无法接续等问题。本轮优先消除这些成本，不减少卡片示例、正文要求、来源阅读与独立审核。

参考 [Codex 开源实现](https://github.com/openai/codex/tree/main)，核对时 HEAD 为 `1715e55076737158ba61d43158ede504de6d4ce1`。实际阅读了该版本的 [apply_patch handler](https://github.com/openai/codex/blob/1715e55076737158ba61d43158ede504de6d4ce1/codex-rs/core/src/tools/handlers/apply_patch.rs)，借鉴局部修改、执行结果与失败回送的机制，未复制其 Rust 运行时或绕过 UNO Gateway。上下文直接采用已安装 DSH 的 `systemPrompt.context`：它将动态状态保存为原生日志中的上下文消息，无需另造请求拦截器。JSON 归一化复用项目已有实现。

## 已实施的能力

| 能力 | 现在的行为 | 数值与边界 |
|---|---|---|
| 稳定上下文 | 系统提示保留完整规范、示例及任务固定目标；当前阶段、预算、检查点、补充要求走原生动态上下文 | 长期偏好与本次要求仍合计 3000 tokens；检查点仍最多 2000 字符；不删除原始日志 |
| 工具回执 | 所有专用 Agent 工具输出先归一化为合法 JSON；错误带类别、原始说明与恢复建议 | 不支持的写入组合明确报错，不静默丢字段；成功收据仍由 Gateway 持久化 |
| 局部修改 | 省略字段保持原值；历史 `action: patch` 可以只改标题或当时的分类字段，也可精确替换正文片段 | 每次 1–32 项 `edits: [{old_text,new_text}]`；原句必须唯一匹配；版本冲突不写入；该旧入口不定义 v3 分类契约 |
| 批量执行 | `compile_batch` 合并已明确的工具操作，按顺序执行并逐项回执 | 每次 1–8 项；单项失败不撤销其他成功项；不能嵌套或切换阶段；读取每项最多 3000 字符，需更多时继续分页 |
| 材料检查 | `compile_inspect` 本地统计段落、链接、图片标记，寻找字面匹配或跨材料重复段落 | 本批最多 12 份；结果默认 30、最多 60 条，支持分页；重复只作候选，不自动删除；不登记全文阅读 |
| 清理定位 | 阅读回执带当前版本的段落 ID；可提交块 ID、唯一原句或原有精确区间 | `exclude_blocks: [{id,reason}]` / `exclude_quotes: [{quote,reason}]`；版本变更后必须重新定位；大幅删减复核保留 |
| 材料组织 | 识别 Markdown 来源头部并保存到来源元数据；短文章内部标题不再变成多个消化对象；沿用筛选时给出的材料类别与理由 | 可识别头部上限 32000 字符；短文正文合计 ≤24000 字符保留整篇；显式 book 仍按章节；旧 Buffer 不自动迁移 |
| 关系质量 | 保存 `basis: source / navigation`；模型整理的类比、对照等阅读入口不冒充原作者论证 | 不新增关系类型，不强制连边数；必须有两端内容支持的维度与边界；搜索和思考保留 basis |
| 发布隔离 | 只沿未发布的出边端点形成发布依赖 | 有问题的入边不阻塞正常目标；循环依赖仍共同发布，合法端点要求不取消 |
| 待办恢复 | 按实际草稿、材料状态和原批检查记录恢复；部分完成优先回到原批待办 | 每次明确恢复处理一个遗留批次，避免反复循环；已发布卡片不重复审核、写入或制卡；不清除累计预算 |
| 思考证据 | 保留摘要和边界；从长卡开头与字面命中的后段抽取有定位的片段 | 正文摘录最多 1800 字符，边界最多 800 字符；保留省略标记与定位；总资料包仍有原来的 22000 字符预算，不增加模型调用 |
| 索引效率 | 重复查询通过索引文件和目标文件的修改时间、大小检查是否变化 | 不再为了确认缓存而读遍所有 Buffer 正文；实际变化后仍重建可丢弃索引；主题改名会使检查失效 |
| 成本观察 | 记录工具耗时、输入输出字符量、错误及固定提示摘要哈希 | `.nexogenesis/agent-metrics/<job>.jsonl`；不额外复制原文、提示词、工具参数或凭据；观测写入失败不破坏成功知识事务 |

## 模型操作示例

局部更新已有草稿：

```json
{"operation_id":"clarify-title","action":"patch","id":"participation","revision":"当前版本","title":"参与：表达与共同决策"}
```

局部正文修订：

```json
{"operation_id":"clarify-boundary","action":"patch","id":"participation","revision":"当前版本","edits":[{"old_text":"唯一匹配的原句","new_text":"修订后的表述"}]}
```

建立阅读导航，单独提交关系：

```json
{"operation_id":"navigation-1","action":"link","id":"participation","revision":"当前版本","link":{"target":"delegation","type":"contrast","basis":"navigation","note":"比较参与范围与决策授权的差异；制度情境不同，不推断效果相同。"}}
```

`compile_task view=receipts` 可按 `id=operation_id` 查收据；`view=pending` 查真实遗留对象。重复原操作必须使用相同参数和操作 ID；修正后的新操作使用新 ID。已成功操作的重试不会作废后来的审核。

## 验证方式

`tests/uno-foundation.test.mjs` 覆盖注册工具 JSON、稳定提示与动态状态、字段保留、原句歧义与版本冲突、幂等审核、Unicode 段落清理、元数据保全、批量失败隔离、阅读边界、导航检索、发布依赖、遗留恢复、长卡后段检索与索引失效。

`tools/eval/uno-foundation-native-smoke.mjs` 使用独立临时知识库、原生 DSH 宿主、模拟 HTTP 模型和独立审核会话，验证模型实际可见的工具、系统提示、批量工具、局部修改与最终落盘。测试端口为 5493/5494；不得直接覆盖占用端口。模拟模型用于协议和生命周期检查，不证明理解能力或真实缓存命中。

只读成本报告：

```text
node tools/eval/uno-agent-metrics.mjs <知识库根目录> <任务ID>
```

报告分别列缓存命中、未命中、输出与缺少 usage 的请求。工具字符数不是 tokens。固定系统前缀不等于供应商一定命中缓存；原生压缩与内部重试仍须核对账单。

## 保留的限制与后续判定

- 目前的程序执行能力是固定 Python 预处理和可组合的数据操作；**不是任意 Python/shell 执行沙箱**。没有把普通子进程或 Node VM 冒充隔离环境。当前材料清理、定位、批量读写已可组合；若真实样本反复需要临时算法，再独立验证受限执行器。
- 卡片忠实度、思想完整性、类比价值仍依赖模型；机械阅读记录不证明理解。没有减少作者/审核的必要证据，也没有用新的固定 LLM 分类链替代自主判断。
- 未引入稠密向量、额外重排模型、自动多代理或更换 Agent 引擎。检索的跨词面召回仍有限。
- 导航标记与新的说明只影响后续操作；旧卡片、关系、原件、筛选结果与已结束任务不自动改写。
- 旧任务恢复能定位真实待办，但缺少旧审核记录时必须重新回查相关证据；不能凭旧模型总结补造阅读记录。

下一轮真实验证应使用相同材料与用途，比较工具错误、输入成本、完整对象数量、遗漏/归属/数字错误，以及导航关系对回答的帮助。不要只比较卡片数或缓存百分比。

## 撤回

本轮没有增加运行时依赖或修改共享 DSH 安装。可回退相关代码、专用工具注册与提示文档；保留所有 Markdown、历史版本和交易收据。新增 metrics 可删除重建；新增 basis 不改变旧关系类型，旧读取器仍能读取关系说明。源代码、构建与正式进程加载分别核对。
