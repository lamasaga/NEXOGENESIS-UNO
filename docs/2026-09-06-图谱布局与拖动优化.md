# 2026-09-06 图谱布局与拖动优化

  修改前程序快照为 Git 提交 `a94ee41`。知识 Markdown、实例目录和坐标缓存未加入该提交。本次修改仅涉及图谱布局、绘制与交互，不改变卡片或关系内容。

## 实际改动

- 布局缓存升级到版本 3。节点集合、领域信息或无向邻接改变时重新计算；仅修改标题、节点颜色或关系的排列顺序不触发重排。
- 同一对卡片之间的重复关系、反向关系只构成一根布局弹簧，自环不参与拉力。原始关系及认知事件的边 ID 保留。
- 近处逐对计算排斥，远处网格按质心近似计算，避免原来的距离截断。弱化中心吸引，增加局部留白，并按不同邻居数对应的节点尺寸进行碰撞避让。
- 利用旧坐标作为起点；小规模新增时允许旧节点适度移动。固定轮数后停止，不在浏览器中持续模拟，也不保证已经求得全局最优布局。
- 计算通过 Node 工作线程执行，同实例的重排串行处理、相同在途请求合并；未变化的图谱直接使用缓存。缓存以临时文件原子替换，版本升级前保留 `layout.json.previous`。
- 静态关系改为每条一根细线，直接连接真实端点，不再按领域弯折成多股束。实际认知活动继续沿原关系显示传播效果。
- 支持整图拖动与滚轮缩放；同实例数据刷新和父组件更新保留当前视角，切换实例重新取景。慢速小步拖动按累计位移识别，取消手势不会留下拖动状态，点击按落点重新判断节点。

  后端回归覆盖关系单独增删、节点删除、缓存复用、输入顺序与重复关系不变性、完全重合节点的分离、旧缓存升级、工作线程响应和同实例串行更新。前端回归覆盖节点面积上限、关系中心路径与原边一致，以及图谱几何构建。

  已用真实图谱快照进行浏览器渲染检查，并用实际 GraphCanvas 组件验证拖动、缩放、面积上限、数据刷新保留视角、慢速拖动与点击区分、手势取消和实例切换取景。隔离预览使用新版模块计算的坐标，不代表原服务已完成重启。

  新计算只能在更新后的服务加载模块后生效。前端构建可以通过刷新加载，后台布局版本需重新启动服务。`/api/health` 中 `graph_layout_version: 3` 用于确认后台已加载；启动器会将缺少此能力的旧服务识别为需要更新的版本。

## 速度、作用力范围与布局恢复（2026-09-07）

  2026-09-07 速度、范围与恢复更新：碰撞收尾改为仅检索已放置节点的相邻网格，移动后重新查询，保持实体圆无重叠；力计算内循环复用数组，减少逐对节点的映射查找。后台默认参数不变，六组稀疏/重合样本与优化前的坐标逐项一致。浏览器交互计算从400轮改为220轮，每6轮预览；阻尼从0.85改为0.7，每轮最大位移从6改为12，连续输入合并时间缩短为60毫秒。新调整以当前显示坐标起算，不再回到后台初始布局。

  三项滑块统一0～4.0、步长0.1，默认均为1.0，旧的更细小数会就近归入新刻度。集中引力权重为数值的1.5次方（最高8倍基础强度）；节点斥力和连线吸引力权重为2的数值次方减1（最高15倍）。连线自然长度同步采用50除以“0.5加0.5倍权重平方根”，默认50、最高档约20.5布局单位，关闭连线力时自然长度不产生作用。这让高档连线力既抵抗拉伸，也明显拉近相连节点；不会取消实体碰撞。该映射仅用于浏览器交互，后台默认布局语义保持原样。

  浏览器按实例保存参数、节点坐标、结构指纹、完成状态和取景位置。结构指纹包含节点、领域及无向去重关系，不包含标题或后台坐标；完整匹配且计算完成时首屏直接恢复，不创建计算线程。结构变化沿用已有节点位置，新增节点采用后台种子后重新校正。计算中按750毫秒限频保存，完成、离开页面或切换实例时再保存；未完成布局重开后从已保存位置继续。恢复默认重置三项参数并从当前位置计算。浏览器存储被清除或不可用时无法保证跨页面恢复；不会写卡片或后台布局缓存。

  当前真实快照的基准测试中，旧强引力计算约15.5秒，新版约4.6秒；新三参数各档样本约1.8～5.5秒，首批预览约0.09～0.18秒。保持其余参数为1时，引力0到4的布局中心距离均方根约452到211，斥力0到4约176到631，连线吸引力0到4的平均边长约60到29，三个控制均有明显作用。此为有限轮数样本测量，不代表任意图规模和极端组合的速度或完全收敛保证。

  12项后台/计算测试与26项前端图谱测试、生产构建通过。Chrome实际图谱测试首批预览约0.25秒，强引力全程约4.4秒；确认刷新和关闭后重开恢复相同节点坐标与取景参数且无计算线程，标题更新不重排、关系变化触发重排、连续调整以当前坐标起算、旧计算取消以及未完成布局从保存位置续算均通过。截图构图一致，不将画布编码字节差异声称为逐像素一致。仍只验证本机Chrome和当前快照。回退可恢复原力映射和单页坐标状态，移除缓存读取与相机恢复；浏览器缓存可忽略，知识体无需迁移。
