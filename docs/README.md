# 文档入口

　　NEXOGENESIS-UNO 当前处于独立重建与验证阶段。新图书编译采用 `unit-cards-v3` / `uno-unit-compile-v3` / `review-publish-repair-v2`，审核和返工区分卡片问题与关系问题；知识分类统一为一个主类型 `type` 与多个既有领域 `domains`，新卡不再写 `tags/topics`。历史 v2 任务按原契约恢复，v1 与更早说明只用于追溯。建构和普通对话使用同一分类读取口径。
