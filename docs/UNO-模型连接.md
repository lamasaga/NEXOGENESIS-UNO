# UNO 模型连接

UNO 使用你配置的模型服务处理对话、编译和建构。连接在当前工作区保存，不会自动复制其他项目的凭据。在线模型会接收任务需要的问题、卡片和材料正文；使用前应确认这些内容适合发送给对应服务。

## 配置连接

1. 打开「设置 → 模型连接」。
2. 选择供应商，输入对应 API Key。
3. 选择模型，或在支持的兼容接口中填写完整模型 ID。
4. 按需点击「测试连接并读取模型」，查看目录与错误提示。
5. 保存当前配置，再开始对话或知识任务。

界面提供 DeepSeek、Kimi 开放平台、Kimi Code Plan、智谱 GLM、阿里云百炼、火山方舟、百度千帆、腾讯混元、硅基流动和自定义兼容接口配置。提供配置入口不等于项目已经实测每个账户和型号；实际权限、额度和服务可用性以你的账户与服务响应为准。

常用模型可直接选择，也可以使用测试返回的模型目录。界面显示实际请求 ID、已登记的文本／图文能力和思考控制。目录没有列出某个别名不一定意味着不可使用；目录出现未知型号也不会自动为它开放未验证的能力。

Kimi 开放平台与 Kimi Code Plan 使用独立凭据和适配路径，不能混用。服务端模型别名可能变化，不应把别名视为永久固定的型号。

## 密钥与自定义地址

已保存密钥不回显；留空表示保留，输入新值表示替换。在同一次设置面板中，切换供应商会分别保留草稿，保存只提交当前供应商；关闭面板后未保存密钥不会保留。

官方供应商使用预设地址。代理、其他地域或其他兼容服务应选择自定义接口，并填写实际支持的 Base URL 和模型 ID。更改自定义地址时必须重新输入密钥，避免把旧端点的凭据发送给新地址。不要将密钥写入卡片、文档或提交到 Git。

## 连接测试能证明什么

「测试连接并读取模型」使用当前草稿发起一次模型目录请求；可以先不填模型 ID，读取目录后再选择。保存时仍须有有效模型 ID。

- 不创建对话，不发送知识正文，不调用生成模型，也不保存或激活配置。
- 只说明目录是否可访问；不证明生成、工具调用、视觉、思考参数或编译计数可用。
- 使用当前输入的密钥，或当前供应商已保存的密钥；不会借用另一个供应商的凭据。
- 请求有超时和响应大小限制，不自动重试或跟随重定向；鉴权、限流、网络和格式错误分别提示。
- 更改连接、切换供应商或关闭面板会取消旧测试，旧结果不代表新草稿可用。

测试只覆盖主模型目录，不测试独立视觉服务。即使填了视觉配置，文档编译也不会因此自动完成扫描件 OCR 或复杂图表理解。

## 对话与知识任务的模型选项

「对话思考深度」用于普通对话。编译和建构使用选定的供应商与模型，但采用各环节自己的思考和输出策略；聊天时的高强度设置不会直接套用到所有审核请求。

模型能力影响可用上下文和输出上限。宿主对知识任务保存所用限制，并检查请求是否可计数；界面提示不支持时不会静默切到无预算约束的执行方式。不要仅凭供应商名称或手填模型 ID 推断支持所有知识处理能力。

开始任务后更改设置，不应理解为正在执行的任务已经更换模型或额度；以任务保存的配置和提示为准。模型请求预算不是金额预算，精修、修复和审核也会增加用量。

## 排查顺序

先核对供应商、地址、密钥和完整模型 ID，再检查账户生成权限与余额；最后区分目录测试、实际生成和任务适配分别在哪一步失败。不要在连接失败时反复重建编译任务。

如果网页提示后端能力不匹配，停止并重新启动当前工作区服务；仅刷新页面不能加载后台代码。程序验证与真实模型效果的工程记录见 [当前实现与验证](UNO-当前实现与验证.md)。
