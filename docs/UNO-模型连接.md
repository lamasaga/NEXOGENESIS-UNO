# UNO 模型连接

> 2026-09-12：参考 NEXOGENESIS-DSH 的供应商与原生套餐适配完善 UNO 设置；只修改 UNO。真实账户和生成能力尚未实测。

## 配置方式

设置 → 模型连接：选择供应商、输入对应 API Key、选择模型，按需测试后保存。编译、建构和思考共用当前 UNO 的连接。官方供应商使用固定地址；代理、其他地域或其他兼容服务使用自定义接口。

常用模型直接从下拉框选择；兼容供应商可手动填写完整模型 ID，也可从连接测试返回的目录选择。界面同时显示实际请求 ID、已登记的文本/图文能力和思考控制；旧别名明确标出当前对应型号。目录没有某个型号不自动否定别名或专属权限，也不静默替换用户输入。模型参数与图像处理折叠为可选项，切换型号时清除不兼容的思考参数；“自动”强度展示当前适配的实际默认档位。

“对话思考深度”只控制普通对话。编译与建构仍使用这里选定的供应商和模型，但采用各自固定、按环节验证的思考策略，避免用户为了聊天临时选择 `max` 后让所有机械审核请求也以最大强度运行。

供应商之间的连接草稿与未保存密钥在打开的设置面板中分别暂存，切换回来仍可继续编辑。保存只提交当前供应商；其他供应商的未保存草稿只留在本次面板内。关闭面板后不保留未保存密钥。已保存密钥不回显，留空表示保留，输入新值表示替换。

Kimi 开放平台与 Code Plan 使用独立凭据。Code Plan 保留四个原生 ID 的选择，普通与高速区分；标准别名 kimi-for-coding 的实际版本由服务端更新，不再固定称为 K2.7。核对时官方已将标准别名指向 K2.8 Preview，详见 [Kimi 官方模型说明](https://www.kimi.com/code/docs/en/kimi-code/models.html)。本次没有扩展底层原生适配的推理档位、上下文或关闭思考能力；这些变化需要另行验证，不能仅靠更新菜单开放。

## 测试的含义

“测试连接并读取模型”对当前输入执行一次模型目录请求，使用本次输入的密钥或该供应商已经保存的密钥：

- 兼容接口读取 Base URL/models；Code Plan 读取其 OpenAI 兼容目录 /coding/v1/models，实际生成继续走原生适配。
- 不创建会话，不发送知识，不调用生成模型，不保存或激活配置；目录可访问不证明生成、工具调用、视觉或思考参数可用。
- 返回目录中的模型 ID、所选型号是否列出、耗时与范围说明。最多展示 500 项，不自动增加未知型号的能力声明。
- 15 秒超时，不重试，不跟随重定向；供应商的错误正文与密钥不返回界面。鉴权、权限、目录不存在、限流、网络及格式错误各有明确提示。
- 自定义端点改变时必须重新输入密钥，不能把旧端点凭据发送到新地址。模型 ID 可以留空先读目录；保存时仍必须填写有效 ID。
- 修改连接或切换供应商会取消旧测试并清除旧结果；关闭面板会取消请求。旧版本后端没有测试能力标记时禁用测试按钮，仍可保存原有配置。

此功能只测试主模型的目录。独立视觉服务没有新增测试请求；新编译仍只处理提取文本，不会因填写视觉设置自动完成 PDF 图表或 OCR。

## 实现与验证

复用现有设置、供应商映射、凭据服务与请求保护；新增 /api/settings/test 和 connection_test_version=1。测试端点不写设置，不绕过模型适配或尝试迁移旧项目凭据。撤回时停用新增测试入口与配置界面变更即可，现有已保存设置格式不变。

11 项新增后端测试覆盖单次请求、隔离凭据、自定义地址变化、缺失与错误凭据、目录校验与大小限制、取消超时、并发限制和无写入。客户端验证提交当前草稿、本地请求令牌与取消信号。完整回归为后端 255 项、前端 164 项，生产构建通过。

Edge / Playwright 在 1440×960 和 390×844 中验证：Kimi 型号选择 → 测试 → 保存 → 关闭重开 → 供应商切换与草稿保留 → 鉴权失败及手动重试 → 动态目录 → 自定义地址校验 → 型号切换重置参数。使用真实 settings GET/PUT/test handler、隔离的设置与凭据存储，供应商目录使用测试替身；页面没有应用错误，故意构造的 HTTP 401 由宿主返回 502 并显示正确提示。Browser 插件不可用，因此使用已安装的 Edge / Playwright。
