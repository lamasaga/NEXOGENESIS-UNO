# UNO UX 与交互优化方案

## 结论与范围

优先优化“用户能否判断下一步、修改范围和操作后果”，而不是整体换肤。现有的编译／建构分工、建构侧重说明、卡片双栏阅读、设置分类和窄屏固定操作栏值得保留。

本方案提出 12 项优化，均为待实施建议。依据为 2026-09-22 对本机 `http://127.0.0.1:3093/` 的实际页面、可访问性树和当前源码的核对。源码基线为 `fc4d5c12837553f6aca163bb0f0189cbf0ea7fcb`；未核验运行服务与该提交完全一致。

实际走查止于操作提交之前：没有发送对话、运行编译或建构、上传材料、保存设置、删除卡片，也没有调用付费模型。运行中任务、部分保存失败和未组织池管理的意见来自源码，不是已复现的线上事故。截图不能证明屏幕阅读器、对比度、触屏或完整键盘操作合规。

与 [稳定性与性能深化修改方案](D:/UESR/Desktop/NEXOGENESIS-UNO/docs/UNO-稳定性与性能深化修改方案.md) 配合实施：前一份解决底层可靠性，本方案定义用户应看见什么、能采取什么行动，以及操作如何得到确认。

## 二、优先级与实施顺序

P1 指可能造成操作误解、丢失草稿或误判保存／授权结果，优先处理；P2 指减少绕路、阅读负担和查找成本。不是漏洞严重度评级。

| 编号 | 优先级 | 优化项 | 依据 |
|---|---|---|---|
| U01 | P2 | 首次提问直接进入可用状态 | 步骤 1＋源码 |
| U02 | P2 | 空材料状态直接引导导入 | 步骤 2＋源码 |
| U03 | P2 | 当前任务获得合适空间，表单分层 | 步骤 1–3、6 |
| U04 | P1 | 开始前明确实际权限和目标库 | 步骤 3、6＋源码 |
| U05 | P1 | 收起、暂停、边界暂停、结束各用一套含义 | 步骤 3 对应组件源码，运行态未实测 |
| U06 | P1 | 设置关闭保护与部分保存回执 | 步骤 5＋源码 |
| U07 | P1 | 弹窗焦点、键盘退出和焦点归还统一 | 步骤 4、5＋源码 |
| U08 | P1 | 资源上限、质量档和能力信息忠于任务快照 | 步骤 2、3＋源码与现行契约 |

| U12 | P2 | 可读性、窄屏导航与非视觉可用性 | 步骤 1–6＋源码 |

### U01｜首次提问不应先完成会话管理

**定位：** [ChatComposer.tsx:63](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/ChatComposer.tsx:63)、[AgentWorkDock.tsx:198](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/AgentWorkDock.tsx:198)、[App.tsx:1324](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/App.tsx:1324)。

建议无会话时仍允许编辑输入；第一次发送才创建对话并提交，不在打开页面时制造空会话。空态用“向当前知识库提问”加明确库名替换抽象说明。保留独立“新对话”入口供熟练用户使用。

兜底：创建失败保留全文；创建成功但发送结果未知时，查回原会话／请求状态，不能重新创建一份。此项依赖会话创建和发送的幂等能力，不能仅放开输入框的 disabled。

验收：首次访问可直接编辑；双击发送只得到一个会话和一条用户消息；创建失败可重试且文字不丢；切库时草稿归属明确，不把旧库草稿静默发送到新库。

### U02｜材料为空时，主操作应是“导入材料”

**定位：** [UnoKnowledgePanel.tsx:345](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:345)、[Sidebar.tsx:209](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/Sidebar.tsx:209)、[App.tsx:1085](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/App.tsx:1085)。

建议按“选择／导入材料 → 核对处理方式 → 开始”排列。空态内提供与侧栏共用逻辑的“导入材料”，显示支持格式与大小限制，限制取自实际服务能力。空列表不显示可点击的全选／清空。仅无待选项时，分别解释“从未导入”与“已归档材料无需重复编译”。

上传完成后保留当前主题和要求，刷新材料列表，明确提示本次新增材料；让用户核对后开始，不自动触发编译。失败显示成功／失败文件数及可重试项，不把上传成功写成“知识已入库”。

验收：从空编译面板无需返回侧栏即可导入；取消文件选择不丢草稿；部分失败不重复上传成功项；未选材料时按钮附近解释原因；上传期间切库不会改变已冻结的导入目标。

### U03｜让工作区服务于当前任务，而不是固定挤在右侧

**定位：** [App.tsx:1253](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/App.tsx:1253)、[App.tsx:1290](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/App.tsx:1290)、[UnoKnowledgePanel.tsx:342](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:342)。

桌面进入编译／建构时，提供“展开工作区／恢复图谱”或可调分栏，使表单拥有足够宽度；保持图谱作为上下文，不要求永久移除。复用现有布局状态，不另建一套页面与控制器。窄屏继续使用现有单列方案。

第一层只放必选材料／范围、当前侧重、授权摘要和主操作；模型资源、详细方法、提示词快捷项放入可展开区域。关键授权不能折叠到不可见；展开与收起不改变字段值。

编译复用建构已有的固定操作栏，显示“已选 N 份材料”“目标库名”，禁用时展示可行动的原因。不要只用悬浮提示解释禁用，因为触屏和键盘用户可能无法触发。

验收：1280×720、1440×900 和 390×844 下主操作可找到；展开工作区、收起面板及恢复时不重置草稿；底部栏不遮挡最后一项；无需滚完整段方法说明才知道怎样开始。

### U04｜“想做什么”与“允许改什么”需要开始前复核

**定位：** [ConstructionControls.tsx](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/ConstructionControls.tsx)、[UnoKnowledgePanel.tsx:366](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:366)。

保留当前“侧重”和“允许调整”的分离。新增紧凑摘要，例如：“主要侧重：发现联系；允许：新增／修改关系、修订正文；另含：移除关系、合并卡片。”实际项目必须来自当前勾选值，不能由侧重名称推断。

标明配置来源“继承自本库设置／本次已调整”。用户切换主要侧重时，不自动覆盖自定义权限；继续保留“按主要侧重配置”这一显式操作。涉及移除、合并、自动建域时，在开始区域用具体结果提醒，避免每次操作都堆一个无信息量确认框。

开始栏使用具体库名、范围、精确模型和本轮请求上限，不只显示“当前知识库”。任务开始后摘要取自任务冻结值，不跟随全局设置变化。

验收：继承配置包含额外权限时，开始前可看见；不勾选合并则提交载荷不含该权限；换库重取配置并明确通知，不静默携带上一个库的授权；对照实际请求逐项验证摘要一致。

### U05｜四类退出行为必须各有一个稳定含义

**定位：** [UnoKnowledgePanel.tsx:305](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:305)、[UnoKnowledgePanel.tsx:313](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:313)、[WorkCenter.tsx](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/WorkCenter.tsx)。

源码中，同一个 `end` 操作在不同分支可显示“暂时关闭”或“结束本次任务”；另有“收起”“暂停任务”“本批完成后停止”等入口。需要统一术语，而不是增加第五种状态。

| 用户动作 | 建议名称 | 必须说明的后果 |
|---|---|---|
| 只关面板 | 收起面板 | 任务继续；能从固定任务入口重新打开 |
| 当前单元安全边界暂停 | 本单元完成后暂停／本批完成后暂停 | 当前单元仍可能保存，之后不开始下一单元 |
| 发出立即停止意图并保留进度 | 暂停任务 | 显示“正在暂停”；底层退出前不显示“已暂停” |
| 终结本次执行 | 结束本次任务 | 已保存内容保留；说明哪些未完成项仍可独立处理，原任务不可继续 |

暂停按钮与边界暂停的差异必须直接可见。只有结束操作需要有信息量的确认，包含已保存、未完成及后续入口；不能把恢复规则藏在“确定吗”后面。停止语义遵守现行契约，不以乐观界面假装底层已退出。

验收：通过合成任务覆盖运行、暂停中、暂停、部分完成、已结束；关闭面板不发 end；点击暂停后迟到事件不能改回运行成功态；所有入口的同名按钮具有相同行为；结束确认不暗示会撤销已保存卡片。

### U06｜设置需要未保存保护，以及分项保存结果

**定位：** [SettingsModal.tsx:83](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/SettingsModal.tsx:83)、[SettingsModal.tsx:113](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/SettingsModal.tsx:113)、[SettingsModal.tsx:162](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/SettingsModal.tsx:162)。

源码已有 `isDirty`，但 Escape、遮罩和关闭按钮直接关闭。建议所有关闭入口共用退出判断：无修改直接关闭；有修改提供“继续编辑”“放弃未保存修改”；需要时提供保存后关闭。保存中禁止含糊退出，明确等待结果。密钥草稿不得持久化到 localStorage 或错误日志。

保存路径先保存基础设置，再保存关联知识库和处理偏好。后一步失败时，前一步可能已生效，但当前反馈统一为“保存失败”。优先提供分区结果，如“模型连接已保存；知识处理设置未保存”，保留失败区草稿，并允许只重试失败部分。不要用一个前端 Promise.all 冒充原子保存，也不要自动回滚已经生效的凭据。

验收：修改普通字段后分别按 Escape、遮罩、关闭和取消均有保护；无修改时不增加确认；模拟第二／第三阶段失败，已保存区显示真实状态，失败区可重试；恢复时不要求重新输入已成功保存的密钥。

### U07｜复用已有弹窗焦点模式，补齐设置弹窗

**定位：** [CardBrowser.tsx:82](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/CardBrowser.tsx:82)、[SettingsModal.tsx:83](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/SettingsModal.tsx:83)、[WorkCenter.tsx](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/WorkCenter.tsx)。

卡片浏览器已有初始焦点、Tab 约束和关闭后焦点归还。设置窗口应复用相同模式：打开进入标题或当前分区的首个合适控件；Tab／Shift+Tab 留在最上层弹窗；关闭回到触发按钮。`aria-modal` 本身不完成这些行为。

弹窗再打开确认框时，只由最上层处理 Escape，避免一键同时关掉确认框和底层未保存设置。标题、错误与表单字段用语义关联；保存反馈应被读出，但不能反复打断输入。

验收：纯键盘完成分区切换、编辑普通字段、保存／放弃并返回；背景控件不被 Tab 到；嵌套确认只关闭一层；焦点触发器已消失时有明确回落位置。另安排屏幕阅读器实测，本次不声称已通过。

### U08｜预算说明应读取实际能力，不显示固定旧常量

**定位：** [UnoKnowledgePanel.tsx:347](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:347)、[UnoKnowledgePanel.tsx:363](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:363)、[UnoKnowledgePanel.tsx:379](D:/UESR/Desktop/NEXOGENESIS-UNO/web/src/components/UnoKnowledgePanel.tsx:379)。

编译说明仍固定写原文与其余上下文各不超过 6 万字符；现行契约存在按精确模型冻结的不同上限。不能统一改成 9 万，也不能将未知能力当作最大能力。新任务展示准备接口返回的有效限制，历史任务展示自身冻结限制；拿不到时写“能力信息暂不可用”，避免显示无依据数字。

“高质量编译”建议改为“逐卡精修（增加请求）”，保留实际增强方法与代价说明，不暗示语义质量已经得到证明。请求上限写成“本轮最多 N 次模型请求，不代表固定花费”；不得在没有价格和材料规模依据时给出精确费用、完成时间或百分比。

正文区优先解释“这会做什么／何时暂停”，协议编号与 token 细节放到展开区；认证失败、服务不兼容等仍给明确下一步，不能用通用重试吞掉原因。

### U09｜任务状态必须同时说明“结果”和“最后确认时间”

### U11｜未组织池先解释问题，再提供对应补救
