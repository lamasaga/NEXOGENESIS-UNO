## 根因与修复

### 中文卡片 ID 在新版草稿入口被拒绝

本批已有卡片的 ID 为中文，包括“这次不同”是债务繁荣中的反复叙事等。搜索和批次清单能返回它们，但 compile_read_card 先查同 ID 草稿，draftRef 对卡片复用了仅接受英文数字的任务 ID 校验，因此在读取正式卡之前抛出“草稿标识无效”。编辑和历史回查也存在同类限制。

模型随后尝试把卡片路径交给原文工具、使用截断的来源引用，产生了额外失败。这些错误没有作为扩大原文工具访问范围的理由；先恢复正确的读卡入口。
