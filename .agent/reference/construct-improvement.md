# 知识组织与验收契约

> UNO（2026-09-12）：下文保留历史 nexo-construct 的内容调整契约。新默认建构只按固定范围生成检索联系，不改写卡片正文；实际接口与边界见 [编译与建构](../../docs/UNO-编译与建构.md)。

  本契约供 nexo-construct 处理内容与结构调整时按需读取。目标是让信息、解释、合理类比、反例和边界更易被使用；不是消除所有孤立节点或为每种情况新增关系类型。

## 调整选择

| 判断 | 倾向动作 | 不应混淆 |
|---|---|---|
| 同一对象重复，差异只是表述 | 合并并保留独有贡献 | 相同主题不等于同一对象 |
| 一卡包含多个可独立使用的问题 | 拆分并保留必要的综合解释 | 字数长、证据多不等于臃肿 |
| 知识对象一致，表达重复或槽位混乱 | 精修正文 | 不以删掉限制换取简洁 |
| 材料已存在但检索难定位 | 调整标题、正文组织、归属或入口 | 尚未定位不等于需新编译 |
| 多个因素解释同一结果 | 查找共同命题与已有模型 | 共同作用不等于两因素之间存在补充、质疑或应用关系 |
| 机制类似、制度条件不同 | 比较映射与失效边界 | 类比不证明目标对象正确 |

## 局部计划

  plan_construct_improvement 的 card_ids 是 1–6 张已完整阅读的源卡，target_ids 是保留或新形成的结果对象；新标识须代表真实独立知识对象。problem 描述使用摩擦，benefit 描述预期收益，alternatives 解释为何不选其它动作。

  preservation 为每张源卡选择少量关键原文锚点（8–500 字）及结果去向，优先选择独有证据、定义、机制条件、真实分歧与失效边界。这些锚点要求保留原文，其余内容可以精简改写；不是全文逐句复制清单。程序只能检查已声明锚点，模型仍负责未列内容的完整性。

  probes 提供 1–3 个具体概念、别名或机制短语及 expected_ids，用同一组查询比较调整前后是否能定位目标。当前测试是完整正文短语定位，不是向量召回评测，更不证明类比或推理质量。语义复核还须回答：原来的知识问题是否改善、重要差异是否可见、有没有把推断变成事实。

  探索用 inspect_knowledge_gap 默认 any，空格分隔词命中任一即可；all 要求同卡全部词，phrase 才是连续短语。结果回显实际词与 matched_terms。验收 probes 仍固定 phrase，避免宽松召回冒充调整收益。合理独立需要当前版本的完整阅读与实际候选比较；未定位或未读齐时记录 evidence_gap。

## 合并与拆分

  合并先确认同一对象，保留不一致来源与条件差异。按真实需要分阶段丰富结果正文、追加源卡来源、迁移关系、处理旧卡。不同层不能同批提交。结果承接所映射源卡的完整 sources；保守多留来源比失去追溯安全，后续精细来源整理另行判断。

  拆分先说明每个结果对象能独立回答什么问题，再创建带来源的完整卡。独立对象不能依赖读者回原卡才能理解成立条件。原卡可保留为有解释力的综合入口，不造空壳导航卡；也可在内容去向与联系迁移完成后退役。

  retire_ids 只能包含不再作为结果对象的源卡。任何活跃卡仍指向待退役对象时，计划不允许执行退役；逐条核对并迁移入边，不把所有边机械复制到所有结果卡。旧 Markdown 与 ID 保留，lifecycle 标记 superseded/archived，不承诺系统已有自动重定向功能。

  计划不是跨事务原子提交器。Gateway 只保证单个事务失败回滚；跨层调整可能留下部分成果，此时 review_construct_improvement(defer) 必须说明已改部分、未完成迁移和下一步。预算无法覆盖来源、关系与验收时先缩小范围，不先退役再补救。重新计划会保留此前工具记录，但不会自动执行撤回。

## 关系与边界审查

  关系裁决 evidence/counterevidence/direction_reason/scope_or_boundary 都是语义判断材料，不是形式配额。共同来源、同年事件、相邻图号只能辅助定位。当前新写关系只能是细分、补充、对照、质疑、类比、例证或应用；每条都要说明两端的具体阅读价值与方向。不能用补充代替相似，用质疑代替一般差异，也不能用应用或例证冒充有效性证明。

  条件反转或沿支持链找到的反对观点，可能反映术语或适用范围差异，先对齐对象、时段、地域与制度。只在同一命题同一条件下真正不相容时建立冲突。找不到反例不等于不存在反例，也不强制创建冲突卡。

## 验收与当前边界

  review_construct_improvement(verify) 核对结果卡、保留锚点、来源承接、退役入边、非法关系和同题定位；reason 说明模型对语义收益的判断。存在缺口继续修正或 defer，无写入可 keep。完成记录绑定对象版本，后续变化使旧验收失效。运行账本不由模型手填。

  当前没有自动证明“表达更准确”或“类比更合理”的算法，也没有一键语义合并、拆分或跨事务撤回。能力来自模型在上述计划内组合真实工具并接受复核；需使用隔离样本与真实新任务比较效果，不以计划字段齐全宣称完整认知能力。

  新建建构保留旧任务与聊天；继续入口沿用原任务和预算。inspect_cognitive_workspace 的 backlog 视图分页汇总当前实例历次建构的结构问题、延期计划和待办，带原任务出处；full 视图读取完整当前工作区。历史事项只供重新核对，不携带旧目标、证据或额外授权，不自动重放已提交操作。原来没有保存的历史发现不能保证恢复。

  一般建构可以连续处理多个局部计划，切换前仍须验收、保持或明确延期，旧计划摘要由运行时保留。单批最多三个同层操作不是整个任务的操作配额。持续任务仍有未决事项时报告部分成果，以 blocked 保存停止理由与待办；不把局部完成说成全库完成。待办重验后可用 deferred_items 保存 backlog_id、resolved/excluded 状态和具体 reason；该语义处置不替代写入与结构复验收据，也不自动删除旧图谱债记录。
