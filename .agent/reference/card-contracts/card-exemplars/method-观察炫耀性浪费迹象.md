## 输入

- 一段可观察的消费、礼仪、语文或公益行为描述；
- 其公开说辞（效率、品味、公益、传统等）；
- 可选：习得成本、可检测的失败方式、谁在示范。

## 步骤

1. 记下公开说辞声称服务的功能（沟通、救济、生产……）。
2. 检查是否同时满足：古旧/累赘、习得昂贵、失败易被察觉、失败带来体面损失。
3. 区分「仍有用的规范」与「主要用作体面测试」的成分；只对后者标为炫耀性浪费迹象。
4. 写清适用场合：哪类人群、哪类场合该迹象最强。

## 输出

　　一份短判断：该行为是否呈现炫耀性浪费迹象、主要靠哪几条判据、尚缺什么证据。

## 适用边界

　　不适用于仅因技术落后而笨拙、但无人以此较劲体面的规范；也不把一切传统自动判为炫耀。用于课堂或消化时的快速透镜，不能替代完整 model 卡。
