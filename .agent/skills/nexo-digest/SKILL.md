# 消化入口已退役

旧的“编译成 Buffer，再消化为卡片”执行链已删除。`/digest` 和 `/消化` 不创建任务，不处理贡献台账，也不恢复旧任务。

用户要把原书处理为卡片时，使用 [当前图书编译入口](../nexo-compile/SKILL.md)。用户要核对历史材料时，可读取真实存在的历史记录与来源，并明确哪些是已有成果、哪些没有完成；不把历史状态作为本轮授权或当前证据。
