# 主题方向与图书编译

`/主题编译`、`/theme-compile` 与 `/编译` 进入同一个原书选择界面，主题要求保留为本轮编译提示。按 [图书编译入口](../nexo-compile/SKILL.md) 执行，不创建章节来源、主题矩阵或第二套控制器。

主题是阅读与组织的关注点，不能据此缩减用户授权范围或把不同作者的机制与边界强行合并。旧主题任务只供查看历史与已有成果，不恢复执行。
