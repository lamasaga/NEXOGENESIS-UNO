# nexogenesis/：历史 Python 入口占位目录

  DSH 版本当前不以本目录作为运行时或知识写入权威。Agent Loop 由 DSH 承载，知识工具与 HarnessGateway 位于 `packages/nexogenesis-tools/`，Web 桥接位于 `packages/nexogenesis-web-host/`。
