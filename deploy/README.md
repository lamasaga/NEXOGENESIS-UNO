# deploy/：服务器部署占位目录

  当前版本只按本机回环服务验证，没有成熟的服务器部署、认证、多用户隔离或容器发布方案。本目录不能作为可直接上线的部署配置。

  本机同源校验、短期请求令牌、会话归属、资源上限与依赖审计已经完成；结果见[当前实现](../docs/history/pre-uno/2026-08-30-当前实现、运行与限制.md)。这些保护只解决本地单用户边界，不等于服务器认证，因此仍不得把 Web Host 直接暴露到局域网或公网。

  若未来进入服务器部署，应先确定真实单用户或多用户需求，再选择认证网关、TLS、数据根隔离、备份与恢复方案；不预先保留未经验证的 Docker、Nginx 或权限架构承诺。
