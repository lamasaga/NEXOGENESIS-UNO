# 本机运行与干净分发

UNO 面向 Windows 本机单用户运行。默认服务地址为 `http://127.0.0.1:3093`，安装与操作见 [项目介绍](../README.md) 和 [使用指南](../docs/UNO-使用指南.md)。

本目录包含工作区运行脚本、运行配置模板和发行白名单，不是一套服务器部署方案。项目不提供成熟的公网认证、多用户隔离或容器发布方案，不应直接把 Web Host 暴露到局域网或公网。

## 本机运行

在项目根目录执行 `prepare-nexogenesis.ps1` 安装项目依赖、构建网页并准备工作区配置，然后运行 `start-nexogenesis.cmd`。需要提前安装 Node.js、npm、Python 和能通过 `dsh.cmd` 调用的运行时。

工作区运行数据保存在根目录 `.nexogenesis/`，具体知识位于 `knowledge-bases/<知识库ID>/`。不要把运行配置或其中的凭据复制到公开仓库。

停止时使用启动窗口的 `Ctrl+C` 或 `stop-nexogenesis.cmd`。重复启动不会重载已经运行的服务，更新后台代码后应先停止再启动。

## 生成空白发行包

以下操作需要完整 Git 工作区；面向使用者的干净发行包不含完整开发与打包工具。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\export-clean-agent.ps1
```

默认在项目旁的 `NEXOGENESIS-UNO-distributions/` 生成 ZIP 和发布清单。可用 `-OutputDirectory` 指定输出目录，`-ReleaseName` 指定文件名；默认不覆盖已有同名输出。

导出读取当前工作区的白名单文件，包括尚未提交的修改，并在清单中记录 Git 提交和工作区是否有改动。因此应先确认准备分享的实际内容，再导出和检查，不要把提交号误认为压缩包与该提交完全一致。

## 程序与知识分离

发行白名单位于本目录的 `clean-agent-distribution.json`。导出只复制程序、运行模板和选定文档，并创建空的知识目录，不复制已有知识库。

以下内容不进入干净发行：

- 具体知识库中的材料、卡片、归档、提取单元、图片和私有记录。
- 根目录及库内 `.nexogenesis/` 中的凭据、实例登记、会话、任务、请求快照和运行状态。
- `artifacts/`、`output/`、`tmp/`、`test-results/` 等知识库之外的编译中间产物、实验与验证输出。
- 已安装依赖、构建输出、日志、语音模型与本机虚拟环境。

Git 忽略规则与发行白名单承担不同职责：前者控制普通文件加入版本管理，后者决定压缩包内容。已经被 Git 跟踪的私有文件不会因为补上忽略规则而自动退出历史，发布前仍需检查跟踪清单和历史。

分发不会删除本地知识，也不等于为知识做了备份。私有备份应在任务暂停、服务停止后保存完整知识库与必要工作区状态，并与公开发行包分开管理。
