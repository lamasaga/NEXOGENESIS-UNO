# desktop/：桌面壳占位目录

  当前仓库没有可用的 Electron 桌面应用。本目录只保留未来打包入口，不能据此宣称已经具备安装包、自动更新或桌面数据迁移能力。

  若真实使用证明需要桌面壳，近期可验证的最小方案是：主进程启动只监听回环地址的 DSH/Nexo 服务，再由 BrowserWindow 加载本地 Web。本机请求边界已经收口，但桌面壳仍需单独验证进程生命周期、协议导航和更新来源，不能直接沿用 Web 原型的安全结论。

  当前运行方式见[《2026-08-30 当前实现、运行与限制》](../docs/history/pre-uno/2026-08-30-当前实现、运行与限制.md)。整理前的融合设计保存在 `docs/history/specs/2026-08-16-nexogenesis-x-dsh-融合设计.md`，仅用于追溯。
